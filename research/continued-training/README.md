# 继续训练与八个新结构复核

本轮在原模型上增加五阶空间滤波器，并单独训练四阶时间组合。原模型的 120 个参数逐位保留；新增的五阶滤波器有 36 个参数。原有权重导出数组也保持逐位相同。

空间训练使用随机解析 Legendre 多项式场的导数标签，4096 个训练样本、2048 个独立验证样本，Adam 2400 步及随后 LBFGS 收敛检查。最后的验证损失为 `2.6540515848291472e-30`。这是算子标签损失，不是瞬态位移相对误差。时间组合的系数和九组解析振子检查分别见 [系数](../../offline/model/time-coefficients.json)、[振子验证](../../offline/model/time-oscillator-validation.json)；它们不能替代三维传播验收。

冻结的推理权重 SHA-256 为 `ee413a70b30e6402e174e8d16a92df9ddd96aaa4a6192df472b74f877311df83`。下面的测试波形没有参与重新拟合或权重选择。

## 独立八例的范围

预先固定随机种子及八个新结构：板、圆管、通孔板、缺口板各两个，包含自由端与固定端边界，每个结构保留八个接收点。全部记录均为 **14 μs**。对比的是相同单元尺寸下的原四阶模型与新五阶模型；五阶模型有更多节点和更高计算成本，并非相同计算量下只增加训练步数的对比。

参考程序单独计算空间细化、阶数提高和时间步减半；检查完整场、接收点 XYZ、材料与几何增量及复数谐波。有效信号采用 5% 相对误差门槛，微弱信号采用预先固定的 `1e-13 m` 绝对门槛。另检查九个预定时间点的物理残差、全部自由节点、初始及固定边界、能量、应变和 J。

初次检查中，固定端通孔案例的参考质量没有通过：一个接收点的微弱材料二次谐波分量在空间/阶数比较中约差 6.8%／7.1%。按评估前已经写入 [计划](planned-inputs.json) 的规则，只对这一案例执行一次进一步空间细化，并保留 [初次完整指标](initial-metrics.json) 和 [初次参考质量记录](initial-reference-quality)。权重及 5% 判据没有修改。

最终汇总见 [指标 JSON](metrics.json)、[逐例 CSV](cases.csv)、[物理检查](physics.json) 和 [细化审计](hole-refinement)。这些文件保留初次失败和复核结果，不能将该组参考细化误称为再次训练。

## 与 5 ms 验证的关系

14 μs 检查不能外推到 5 ms。新长记录功能使用训练后的时间组合，但四阶、五阶空间设置仍有不同的离散误差。本版的 [20 组 5 ms 验证](../long-validation/README.md) 检查默认四阶设置，未通过精度验收；更高阶参考的收敛也要独立验证。软件以研究版提供，不将这八例的短记录结果作为长记录或任意工况的精度证书。

训练和复核源码位于 `graphwave/continue_training.py`、`graphwave/evaluate_continuation.py`、`graphwave/continued_validation.py`。汇总脚本 `tools/summarize-continuation.py` 只合并已完成的固定计划结果，不拟合权重。推理权重和训练记录已随软件交付；便携运行时用于预测与分析，再训练需要从完整源码准备 PyTorch 环境。
