# 混频分析的核对（2026-11-21）

结果页新增了“混频”分析：模型有两个载频 f_a、f_b 时，沿点列提取和频 f_a + f_b、差频 f_b − f_a 的分量和混频比 A±/(A_a·A_b)（[使用说明](../../docs/nonlinear-analysis.md)第 4 节）。这里用一个有闭式解的算例核对它：两列共线的平面纵波。

| f_a、f_b 处的波数 | 0.393217、0.491521 rad/mm | ω/c | −0.0003%、−0.0004% |

和频和两个二次谐波与理论一致到 1% 以内，说明分析对任意频率分量的提取是对的。差频的两项差 2%–3%：差频只有 0.1 MHz，40 μs 的猝发音里只有 4 个周期，“连续波”的前提最弱。

核对过程中发现并修了分析的一个缺陷：两个频率的合成包络有拍，原来“取第一个包络峰”的到达时刻落在第一个拍上，时间窗偏离了猝发音的中心。现在按拍的周期平滑后再取。

## 1. 理论

四个侧面都是对称面的杆里是平面纵波（单轴应变）。一维方程 ρu_tt = C₁₁u_xx(1 − βu_x)，β = −(3 + C₁₁₁/C₁₁) = 10.364（软件的铝）。对 u₁ = A_a cos θ_a + A_b cos θ_b 作二阶摄动：

    u₂ = β x (∂ₜu₁)² / (4c²)
    ⇒ A₊ = A₋ = β k_a k_b A_a A_b x / 4，A(2f_a) = β k_a² A_a² x / 8

所以混频比 A±/(A_a·A_b) 随距离的斜率是 β k_a k_b / 4 = 5.008×10⁵ m⁻²。纵波没有频散，和频、差频都是相位匹配的，波数是 k_a ± k_b。

**窗的因子。** 上面是连续波的幅值。分析对猝发音取 Hann 加权的 Fourier 系数：包络为 E(t) 的分量读出来是幅值乘 ⟨WE⟩/⟨W⟩，由两个分量相乘产生的分量是 ⟨WE²⟩/⟨W⟩。所以每个比值都比连续波的值大同一个因子 ⟨WE²⟩⟨W⟩/⟨WE⟩²。40 μs 的 Hann 猝发音配 60 μs 的 Hann 窗（默认：激励时长的 1.5 倍）时它是 1.3587。表里的理论值已乘这个因子。

## 2. 算例

杆 300 × 0.8 × 0.8 mm，端面牵引 10 MPa，信号是一个双频猝发音（0.4 和 0.5 MHz 等权，Hann 包络，40 μs）。32 个接收点在 20–119.2 mm，间隔 3.2 mm。三组控制都算，和频、差频取非线性增量。时间窗跟随波包（实测群速度 6393 m/s，理论 6391.5 m/s）。

```sh
export WORKAI_VERIFY_JOBS=<放计算记录的目录>
python research/wave-mixing/mixing_bar.py run        # 约 10 分钟
python research/wave-mixing/mixing_bar.py analyse    # 调用软件自己的混频分析，写 results.json
```

## 3. 说明

- 和频处点距 3.2 mm 接近半个波长（3.55 mm），软件对这个波数给出了“点距太大，不可靠”的提示；数值本身与 k_a + k_b 差 0.04%。精简记录最多 32 个接收点，这段距离上加密不了；用完整记录的线段采样可以取得更密。
- 这个核对只覆盖了共线的纵波。板中导波的混频（两个模态、相位匹配表）只有单元测试，没有算例核对。
