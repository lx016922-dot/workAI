# P1 COMSOL 首批六个基准

本批包含 A、B、C 三个工况的 Murnaghan 与线性基准，以及同源的材料自检。计算使用 COMSOL 6.4、四阶 nodal serendipity（shnserp）六面体和 20 阶积分。A、B 各 360 个六面体、22,167 个自由度，C 为 540 个六面体、30,711 个自由度。

- [位移 CSV 与工况元数据](data/)采用项目的 601×40 格式。每个算例记录 0–30 μs，每隔 0.05 μs 采样，含 13 个接收点的三分量位移，单位为 m。
- [应变和 J](data/field/)保留每个输出时刻的最大 Green 应变和最小 J。
- [材料自检和完成回执](evidence/)记录应力张量、求解参数、耗时和输入身份。
- [校验报告](data/validation.json)记录文件完整性、输入哈希、时间网格、零初值、自由度、应变和 J 的检查，以及新旧线性波形的比较。用 [SHA-256 清单](SHA256SUMS.txt)核对归档文件。

六份基准均通过完整性及应变／J 检查。新旧线性波形的相对最大差按全部时刻和分量的最大绝对差除以旧波形的绝对峰值计算。三组均高于文档的 1×10⁻⁶ 复现目标。

| 工况 | 新旧线性相对最大差 | 本批 Murnaghan 与线性相对最大差 |
| --- | ---: | ---: |
| A | 5.54×10⁻⁶ | 1.06×10⁻⁴ |
| B | 1.28×10⁻⁶ | 3.67×10⁻⁴ |
| C | 1.19×10⁻⁶ | 5.73×10⁻⁵ |

StVK、时间步与网格收敛，以及非线性 2f 的参考对照仍待补齐。
