## WorkAI 超声导波仿真 1.0.1 · Windows 桌面版

非线性超声导波物理 AI 仿真软件的桌面正式版。下载 `WorkAI-1.0.1-windows-x64.zip`，完整解压后双击 **WorkAI.exe** 即可使用：本机离线运行，不需要安装 Python、COMSOL 或其他软件，也不需要联网。

### 1.0.1 修复
- **快速引擎（粗网格算子）在 Windows 上不可用**：1.0.0 的压缩包在 Windows 构建机上检出时，模型文件的换行被改成 CRLF，校验值与评估记录对不上，选择快速引擎后“消息”窗口一直显示“evaluation-abcd.json 不是这个模型的评估。”，也无法计算。现在模型文件按原字节打包，校验也不再受换行影响；打包测试会在 Windows 上预检两个快速模型并实际运行一次快速引擎计算。
- 边界条件说明：对称面、反对称面在“设置”窗口和使用说明中给出含义与适用条件。

1.0.0 用户：下载 1.0.1 解压到新目录即可；以前保存的模型文件（.json）可直接打开。

### 界面
仿照工程仿真软件的布局：
- **功能区**：文件、主屏幕、几何、材料、物理场、网格、研究、结果、视图、帮助；
- **模型开发器**：模型 → 组件（几何、材料、超声导波物理场：激励源 / 边界条件 / 接收点、网格）→ 研究（瞬态记录、求解器）→ 结果；
- **设置窗口**：编辑所选节点，小节可折叠；
- **图形窗口**：三维模型、激励信号（时域与频谱）、结果（位移场动画、任意点波形与频谱、多点提取、五种响应）；
- **消息 / 进度 / 日志窗口**，以及状态栏。

### 功能
- 几何：平板、圆管、带通孔板、带缺口板；
- 材料：多晶铝（Murnaghan 三阶）、各向同性 Murnaghan 自定义常数、自定义应变能 W(E)（如 CFRP）；
- 激励：多个激励源，猝发音、高斯脉冲、Ricker、线性调频、多频合成、任意采样信号；均匀、高斯、梳状分布；
- 边界：对称面、反对称面、吸收层、固定面；
- 计算：冻结图网络（等价于 GLL 谱元），线性 / StVK / 完整三组控制同时计算；记录最长 20 ms，长记录可暂停续算；
- 结果：完整、线性、StVK、几何增量、材料增量五种响应；可导出全部结果 ZIP。

### 已做的核验
文献与解析解对照（材料常数、波速、Lamb 波频散、二次谐波、吸收层）、1 ms 长记录精度、缺口与通孔散射、管中导波与管端反射，详见源码仓库 `research/` 目录。

### 系统要求
Windows 10 / 11 64 位；建议 8 GB 以上内存、10 GB 以上可用磁盘。界面由系统自带的 Microsoft Edge WebView2 显示（缺失时自动改用默认浏览器）。

### 校验
`SHA256SUMS.txt` 给出压缩包的 SHA-256；解压后可运行 `runtime\python.exe verify-package.py` 逐文件校验。
