WorkAI 超声导波仿真 1.2.0（Windows 桌面版）
==========================================

非线性超声导波物理 AI 仿真软件。冻结图网络等价于 GLL 谱元离散，逐时前向计算线性、
几何非线性（StVK）和材料非线性（Murnaghan / 自定义应变能）三组响应。本机离线运行，不需要联网，
不需要安装 Python、COMSOL 或任何其他软件。

一、安装与启动
--------------
1. 系统要求：Windows 10 / 11（64 位），建议 8 GB 以上内存、10 GB 以上可用磁盘。
2. 把下载的 ZIP 完整解压到一个可写目录，例如 D:\WorkAI。不要在压缩包内直接运行，
   也不要解压到 C:\Program Files 等需要管理员权限的目录。
3. 双击 WorkAI.exe。启动画面消失后进入主窗口。
4. 界面由系统自带的 Microsoft Edge WebView2 显示（Windows 10/11 通常已安装）。若提示未安装，
   程序会改用默认浏览器打开工作台；也可从微软官网安装“WebView2 运行时”后重新打开。
5. 数据（计算记录、日志）保存在程序目录下的 data 文件夹；该目录不可写时改用
   %LOCALAPPDATA%\WorkAI\data。

二、界面
--------
- 功能区（顶部）：文件、主屏幕、几何、材料、物理场、网格、研究、结果、视图、帮助。
- 模型开发器（左）：模型 → 组件 1（几何、材料、超声导波物理场：激励源 / 边界条件 / 接收点、网格）
  → 研究 1（瞬态记录、求解器配置）→ 结果（计算记录）。右键节点可添加或删除。
- 设置（中）：编辑所选节点的参数，各小节可折叠。
- 图形窗口（右）：三维模型（拖动旋转、滚轮缩放、Shift+拖动平移、点击选中）、激励信号（时域与频谱）、
  结果（位移场动画、任意点波形与频谱、多点提取、五种响应、导出 ZIP）。
- 消息 / 进度 / 日志（右下）：模型检查、网格与记录大小、2f 分辨率、验收范围提示、计算进度和运行日志。
- 状态栏（底部）：当前状态、网格与记录摘要、版本。
- 快捷键：Ctrl+O 打开模型，Ctrl+S 保存模型，Ctrl+Z 撤销，F8 计算，F1 使用说明。

三、基本流程
------------
1. 主屏幕 → 新建：选择模板（平板、圆管、带孔板、带缺口板、顶面高斯激励、双贴片、CFRP 等）；
   或“打开”以前保存的模型文件（.json）。
2. 在模型开发器中依次检查几何、材料、激励源、边界条件、接收点和研究设置。网格由软件自动选择
   （按激励频率、记录时长和缺陷位置），“网格 1（自动）”节点显示所选尺寸和依据。
   模型大小只受本机内存、磁盘和时间限制：“消息”窗口显示预计耗时、内存和记录大小。
   缺陷：功能区“几何 → 一键添加缺陷”添加裂纹、孔、分层、接触界面或缺口，在“设置”窗口修改位置和尺寸；
   裂纹和分层可设为“闭合”（受压时接触传力、受拉时张开，产生接触非线性的高次谐波）。
   文字描述：在顶部文字框输入，例如“在 100 mm 处添加深 0.5 mm 的裂纹”“在 30、60 mm 处各加一个直径 1 mm
   的通孔”“在 60 到 80 mm 之间添加分层，距上表面 0.8 mm”“板长改为 200 mm”，按回车，确认后修改模型。
   边界条件：对称面即镜像面，几何、材料和激励都关于该面对称时只算一半模型，结果与整体相同
   （面上法向位移为零）；反对称面用于激励镜像后反向的情况（面上切向位移为零）；
   吸收层吸收端面反射；固定面上位移为零。
3. 查看“消息”窗口：显示“模型检查通过”后即可计算；注意 2f 分辨率和验收范围提示。
4. 点击“计算”（F8）。首次计算需要几分钟编译；“进度”窗口显示进度和预计剩余时间。
   计算可以“暂停”，之后从检查点“继续”。
   大模型（全部节点的完整记录超过 2 GiB）自动保存精简记录：接收点保存全部采样点的完整波形，
   动画用抽稀的表面网格，另存 4 个时刻的完整位移场。请在计算前把关心的位置设为接收点；
   记录方式和时间层可在“求解器配置”中指定。
   “求解器配置 → 计算的响应”决定算几组本构控制：默认三组（线性、StVK、完整）都算，得到五种响应；
   只需要完整响应或总的非线性增量时可以少算，省时间、内存和磁盘。
   计算自动用上全部 CPU 核，结果与单核逐位相同。
5. 在“结果”下选择计算记录查看结果，可导出全部结果 ZIP（配置、完整时域记录、网格和校验摘要）。

四、精度与适用范围
------------------
- 精度由节点间距决定。自动网格的 2f 分辨率目标为 10，1 ms 及以上的记录为 15（实测 1 ms 末误差约 0.1%）；
  本机内存放不下模型时才放粗，并在“消息”窗口提示。
- 时间层默认“自动”：按本模型实测的稳定极限和相位误差上界（0.01 rad）选择最省的时间层，
  短记录用二阶单级，长记录用三级四阶；要逐位重现旧版本结果，在“求解器配置”中选“训练时的时间层”。
  含闭合裂纹、闭合分层或接触界面的模型也用自动时间层（界面刚度不变），比以前少算约 3 倍。
  自动时间层下，波还没有到达的区域里小于 2.2e-308 的数当作零，记录开头不再变慢；只有比信号小两百多个
  数量级的数会变，“训练时的时间层”不做这个处理。
- 快速引擎（“求解器配置 → 计算引擎 → 粗网格算子”）：在粗网格上用学到的单元算子计算，只适用于无缺陷或含孔的铝板。
  精确模型（h 2 mm）在板长 200 mm、记录 100 μs、半宽 8 mm 以内与 1 mm 细网格对照，43 组接收点中 42 组的波形、
  基频和二次谐波相差在 5% 以内，比细网格快 3–22 倍；快速模型（h 3 mm）更快，但二次谐波随传播距离变差，
  只建议在训练范围（48 mm 板长、30 μs）内使用。含孔的模型须用精确模型；裂纹、分层、接触界面和缺口请用冻结网络。
  核验报告见源码仓库 research/coarse-range。
- 缺陷的网格与同一网格上的谱元求解器一致到 1e-10，接触界面通过一维解析核对；裂纹、分层的散射
  和接触非线性的独立核对（COMSOL）见源码仓库 docs/comsol/defects。
- 已与文献、解析解和独立求解器核对：材料常数与波速、Lamb 波频散、二次谐波、吸收层、1 ms 长记录、
  缺口与通孔散射、管中导波与管端反射。核验报告见源码仓库 research/ 目录。
- 新的几何、材料或激励组合属于研究结果，应用细网格参考逐例核对。

五、资源
--------
- 完整记录未压缩上限 = 采样点数 × 节点数 × 3 方向 × 8 字节 × 3 组控制；程序在计算前检查磁盘空间。
- 同一数据目录只能运行一个 WorkAI 实例。
- 退出时若正在计算，程序会询问；长记录已保存的分块下次打开可继续。

六、其他
--------
- Start-WorkAI-Browser.bat：不用桌面窗口，改在默认浏览器中打开工作台（保留启动窗口，按 Ctrl+C 退出）。
- verify-package.py：用 runtime\python.exe verify-package.py 校验软件包文件完整性。
- 命令行：WorkAI.exe [--data 目录] [--devtools]
