## 运行

要求 Node.js 22 或以上（已测试 24.19.0），无需第三方 npm 运行依赖。此环境还需要已恢复的 `/workspace/workai-remote`：已配对身份、连接报告、原协议、PowerShell 7.6.7 和签名客户端。**仅下载本仓库不能重新生成已有身份。**

```sh
cd /workspace/workAI
npm ci --ignore-scripts --offline --no-audit --no-fund --cache /tmp/workai-npm-cache
bash solid/prepare-solid.sh
npm start
```

默认仅绑定本机回环地址的 3000 端口。此云环境设置界面不提供本机网页预览；启动成功也不代表网站已经发布。不要把环境设置里的「发布」当作发布一个新站点。

| 环境变量 | 用途 / 默认值 |
| --- | --- |
| `WORKAI_REMOTE_ROOT` | 已恢复的客户端目录，默认 `/workspace/workai-remote` |
| `WORKAI_STATE_DIR` | 网页任务记录目录，默认 `$WORKAI_REMOTE_ROOT/web/jobs`；模型放在同级 `models` |
| `PORT` | 网站端口，默认 `3000` |
| `WORKAI_HOST` | 监听地址，默认 `127.0.0.1` |
| `WORKAI_WEB_ORIGIN` | 外部部署的 HTTPS 源地址，不带路径 |
| `WORKAI_WEB_PASSWORD` | 外部访问的密码，至少 16 字符，必须通过部署环境安全配置；登录用户名 `workai` |

允许外部访问时，需要带 HTTPS 的反向代理、访问认证以及到原 COMSOL 服务器的 Tailscale 网络。配置 `WORKAI_WEB_ORIGIN` 后反向代理须保留该源的 Host。服务器在外部监听或使用外部源时强制要求密码和 HTTPS 源。不要将私钥放入前端、公开站点、仓库、ZIP 或聊天中。

默认使用平台的 VPN / HTTP 代理访问 `http://100.100.205.105:18765`。不要在云容器中另装 Tailscale 客户端。Windows 服务器的原 HTTP 监听程序必须保持运行。无须更换已经配对的身份。

## 数据与计算行为

- 服务器保留的任务编号会从已有 `requests` 目录导入。没有远程「全部任务」接口，其他历史任务需要按编号加入。
- 模型校验保存只处理数据，不会启动 COMSOL。编辑后的模型须保存才能提交。新模板是示例参数，不是已恢复的历史模型。
- 提交会先保存任务编号与不可变的模型参数，再调用签名客户端；网络中断时不自动重发 POST。先查询相同任务编号。
- 页面上的计算按钮会启动真实远程计算。网站本身不自动运行、取消或清理远程任务，也不更新 Java 模型代码。
- 所有服务响应（包括错误）由恢复客户端验证；下载文件还要通过已签名清单的长度、SHA-256 以及本地文件验证。
- 远程签名下载器当前每个文件限制 1 MiB。大型 MPH / 场结果需要扩展流式校验下载器；不能声称完整生产结果已迁移。本地三维模块使用独立、有上限的完整场存储。
- 二维研究 A 扫展示实际 u/v/w 位移。波形身份、数量和时间网格须完整匹配，三组离散差异不自动标为科学收敛。场采样 CSV 可下载。非线性模板对同一载频的五组对照作谐波分析；该 COMSOL 分支的场动画和模态分离尚未接入。本地三维模块已提供真实位移场动画。
- 固定一维验证图中的 3 MHz 与 6 MHz 是独立计算，不是同次激励的基频与二次谐波，不能据此计算非线性系数。原站三维场历史、实验校准和项目数据库仍未恢复。
- 网页的任务和模型状态写在仓库外；客户端私钥始终只由既有签名辅助进程使用。网页没有任意命令、文件路径或模型代码上传接口。
