# 三维跨工况 AI 训练

本模块训练一个共享的、以三维几何和激励为条件的位移场网络。权重跨工况共享，没有为每个案例单独学习一个编号向量。输入包含实际四面体网格的边界坐标、外法线、加载区域、固定边界和激励参数；输出任意网格节点、时间上的三分量位移。参数化板、管、通孔板和缺口板已经进入实际训练。

本文保留前两轮的原始记录；后续 56 工况、独立分支和第三轮结果见[训练改进记录](operator-training-improvement.md)。不要把前后不同的最终测试集合当作同一盲测重复比较。

这是通用模型方向的首批实验，**不是已经验证了任意形状预测能力的成品**。目前没有把神经网络接入求解器路由；原三维有限元动画与任意方向波形功能保持可用。此前二维 PINN 的记录与权重单独保留。

## 数据与独立测试

本轮新增 32 个物理几何工况，每个工况运行线性、StVK 几何非线性和完整 Murnaghan 三组真实有限元控制，共 96 次求解。三组使用完全相同的网格、内部步长和输出采样，完整场均保存 float64。输入、完成记录、原始与压缩场、网格、求解器源代码均核对 SHA-256。

范围为 10–14 mm 长、矩形截面约 3.5–4.5 × 1.6–2.4 mm，管外半径 2.3–3 mm；0.18–0.25 MHz、1.5–2 周期、0.75–1.5 MPa，改变激励方向、延迟和相位。记录 0–14 μs，输出间隔 0.05 μs，目标网格 0.65 mm。材料固定为文献多晶铝；未包括接触、塑性、损耗或其他合金牌号。

初轮 16 个案例按 8/4/4 分组，完成 2,000 步训练。检查发现验证集全是自由边界，而测试集全是固定边界，不适合评估同时覆盖两者的模型选择。这项不足和初轮失败结果均保留。第二轮把全部已经查看过的初轮案例归入开发训练集，另外生成 16 个新几何，形成 **16 个训练、8 个验证、8 个最终测试工况**。每个新验证/测试集合都在四类结构中包含自由与固定边界各一个案例。源端面与固定条件仍有关联，不代表所有参数组合已经独立覆盖。

划分单位是完整几何，不把时间帧、控制组或网格重复随机拆到不同集合。第二轮新的测试几何与训练、验证几何完全不重合。验证集用于选择检查点；测试只在记录选定权重的摘要后评估。初轮测试已经用于开发判断，所以不再宣称它们是第二轮未见测试。

当前标签经过完成状态、摘要、同网格和有限值核对，但**这些新几何尚未逐个完成空间/时间细化验收**。网络与标签接近也不能证明物理解准确，这一项作为单独的未通过门槛保留。

## 网络与物理约束

边界点编码器采用共享 MLP，对所有真实表面三角形作面积加权平均与最大值汇聚；编码包含内孔/管腔表面，不用实心包围盒替代空腔。条件向量包含尺寸、源位置、幅值、方向、载频、周期数、延迟、相位、记录时长和固定边界标记。坐标解码器使用三维坐标、时间及通用 Fourier 特征；不使用纯 S₀ 模态增长律。

输出分成线性位移、几何增量、材料增量三个向量，累加得到三种本构响应。各分支尺度只由训练场的体积加权均方值计算，避免材料增量被大幅基频淹没。三个方向均可非零，没有二维平面应变约束，也没有硬编码 A² 标度。

| 约束 | 实现 |
| --- | --- |
| 本构 | 三维 F=I+∇u、E=(FᵀF−I)/2、Murnaghan 能量与第一 Piola 应力 P=F∂W/∂E |
| 动量 | 真实四面体 P1 形函数与集中质量的弱残差，内部节点和自然边界节点分别计算 |
| 激励与自由边界 | 对实际表面名义牵引作面积积分；无加载表面的自然边界力为零 |
| 初始条件 | 输出乘以延迟后时间的平方门函数，初始位移和速度严格为零 |
| 固定边界 | 指定固定节点输出严格为零；不把支承反力误当成零牵引 |
| 使用范围 | 应变范数超过 0.001 或 J 非正的惩罚，并单独报告采样检查 |

训练动量残差使用时间中心差分，步距 0.025 μs。内力使用 SI 单位，归一化采用 L₀=10 mm、T₀=1 μs、U₀=100 nm，按分支训练尺度与载频角频率平方进一步归一化。增量方程用相邻本构控制的内力之差；外部激励只出现在原线性控制方程中。

这些是**离散、采样的软约束**，不是全连续域的严格证明；未额外加入全域能量误差项。三阶展开的应变限制不是实测屈服条件。网络的几何编码也不保证对任意刚体旋转等变；本构公式的客观性单独测试。

## 实际运行和保存

使用已有 PyTorch 2.9.1+cpu，float64、2 个线程。第一轮宽度 64、2,000 步；第二轮宽度 96、8,000 步，从新初始化开始。第二轮先进行 1,500 步数据预热，再在 400 步内把动量/边界权重升到 0.001，其后联合训练。优化器为 Adam，初始学习率 0.0025，余弦下降。第二轮随机种子 2026102303。

每 50 步保存损失、优化器、随机数状态和最后权重。联合阶段开始后的验证分数用于选定最佳检查点；最终测试不改变权重。模型和工况存放在仓库外：

```text
/workspace/workai-remote/training3d/
  campaigns/aluminum16-20261023/
  campaigns/aluminum32-20261023/
  runs/aluminum-operator3d-20261023-v1/
  runs/aluminum-operator3d-20261023-v2/
  latest.json
```

每个运行保留 `best.pt`、`last.pt`、`config.json`、`dataset.json`、`history.jsonl`、`metrics.json`、`probe-predictions.npz`、`source_snapshot/` 和测试前固定权重摘要。不要覆盖旧运行目录或把权重、完整场、连接身份加入源码包。

```sh
# 安装只检查依赖与物理测试，不训练或生成案例。
bash training/prepare-training.sh
# 显式启动新训练；NEW-RUN 必须尚不存在。
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /workspace/workai-remote/training/venv/bin/python -m operator3d.train \
  --campaign /workspace/workai-remote/training3d/campaigns/aluminum32-20261023/manifest.json \
  --run-dir /workspace/workai-remote/training3d/runs/NEW-RUN \
  --steps 8000 --width 96 --physics-weight .001 --data-warmup 1500 --seed 2026102303
```

中断后可用相同命令参数加 `--resume`，且源代码摘要必须与该运行一致。源码已演进时应从该运行的 `source_snapshot` 工作目录运行冻结版本；不能静默用新实现接续旧优化器。已完成运行不需要重训。第二轮模型评估重载工具为 `tools/review-operator3d.py`。

工作台“AI 训练”读取真实三维运行状态并自动刷新准备、训练和评估阶段；接口只读，不会因打开页面而启动计算。完整场误差、材料增量误差、材料 2f 复数差异、物理残差及标签离散精度分别列出。谐波分析采用完整记录 Hann 窗，包含反射，不解释为单一导波模态。

六项新 PyTorch 测试覆盖能量梯度/本构客观性、质量与仿射内力、时间差分、零初始/固定条件、三分量与查询排列、可反向传播的物理残差、完整几何隔离和新验证/测试边界平衡。软件测试通过不代表模型精度通过。

## 2026-10-23 实际训练结果

两轮均已结束，没有遗留后台训练。第一轮 2,000 步耗时约 74 秒；第二轮 8,000 步耗时约 341 秒，包括最终评估，不包括生成有限元标签。第二轮最佳检查点由验证集选在第 6,050 步，在读取最终测试指标前固定了权重摘要。两轮的测试集合不同，不能直接把它们的误差作前后改进比较。

第二轮 8 个独立测试几何的结果如下。完整场与材料增量均为全记录、三分量、质量加权相对 L2 误差；材料增量是真实完整响应与几何非线性控制之差。

| --- | --- | ---: | ---: |
| 板 | 自由 | 51.39% | 62.27% |
| 板 | 一端固定 | 55.76% | 68.66% |
| 管 | 自由 | 83.93% | 80.37% |
| 管 | 一端固定 | 88.85% | 214.38% |
| 通孔板 | 自由 | 57.11% | 65.06% |

完整场误差的等工况算术平均为 72.40%，材料增量为 92.06%；不是把所有网格混合加权的总体值。16 个点位/方向的材料 2f 复数误差为 9.79%–355.77%，等点位平均 144.57%。所有参考幅值均超过当前 0.0001 nm 报告下限，但该下限不是标签离散误差的证明。
