# 换能器模型：斜楔和压电片

激励源的“空间分布”里多了两种换能器，结果页的沿程分析里多了“接收方式”。它们按**换能器加在板面上的牵引**来建模：不建压电体、楔块和耦合层，电压到牵引的换算（换能器的灵敏度和频响）需要标定。

这样做能回答的是：这种换能器会激出哪些模态、各占多少、朝哪个方向，以及它接收时对哪些模态敏感。A₂/A₁² 这类比值不依赖灵敏度的绝对值，但依赖 f 和 2f 两处灵敏度之比，这个比值要由实验标定。

核对报告：[research/transducers](../research/transducers/README.md)。

## 斜楔换能器（激励）

斜楔把压力波斜着送到板面。板面上的牵引是一列沿表面行进的波 `s(t − x/v)`，行进速度（迹线速度）

    v = 楔块声速 / sin(入射角)

它选出相速度等于 v 的导波模态（Snell 定律）。

“激励源 → 空间分布 → 斜楔换能器”：

| 参数 | 含义 |
|---|---|
| 行进方向、朝负方向行进 | 行波沿哪个面内坐标轴走 |
| 底面长度、宽度 | 楔块与板的接触区；宽度 0 表示整个面宽 |
| 表面迹线速度 | 要激发的模态的相速度；可由楔块声速和入射角计算（有机玻璃纵波约 2720 m/s） |
| 幅值分布 | 均匀，或 Hann（两端渐降，旁瓣小） |

- “牵引方向”一般取面的内法向（压力）。“作用中心”是底面的中心；“延迟”是行波进入底面的时刻。
- 记录时长要盖住猝发音加上行波走完底面的时间。
- 一个模态被激发的强弱由底面的波数谱决定：均匀分布时正比于 `sinc((k − k_t)L/2)`，k 是模态的波数，k_t = ω/v，L 是底面长度。底面越长，选择性越强。
- 内部把底面分成一排互相重叠的条带，每条的信号延迟到它的位置（延迟的线性插值），每个迹线波长至少 10 条，最多 64 条。底面超过约 10 个迹线波长时会拒绝并说明。

## 压电片（激励）

粘贴的压电片伸缩时，通过边缘处的面内剪力带动板（pin-force 模型）：片伸长时，牵引指向片外。

“激励源 → 空间分布 → 压电片”：

| 参数 | 含义 |
|---|---|
| 形状 | 条形（两条边）、矩形（四条边）、圆片（径向的一圈） |
| 长度（圆片为直径）、宽度 | 压电片的尺寸；条形片宽度 0 表示整个面宽 |
| 边缘传力区宽度 | 剪力分布的宽度，在片的边缘以内；至少盖住一排网格节点 |

- “牵引方向”是片的长度方向，必须在加载面内（圆片不用它，但也要在面内）。
- “幅值”是传力区里的剪切牵引；线力 = 幅值 × 传力区宽度。
- 条形片激发波数为 k 的模态，强弱正比于 `sin(k(a − e/2))·sinc(ke/2)`，a 是半长，e 是传力区宽度：片长约为半波长的奇数倍时最强，整数倍波长时为零。这就是压电片的“模态调谐”。

## 接收方式（结果页 → 沿程累积）

默认是点接收（激光测点）。在等距的点列上还可以选：

- **斜楔换能器**：给出沿线的长度和迹线速度。把底面范围内各点的位移按到中心的距离对齐后取平均。相速度等于迹线速度的波同相叠加，其他的部分抵消。
- **压电片**：给出长度。取两端位移之差，即平均应变乘以长度（接收方向取沿线的面内方向）。

只算了换能器沿线的长度；垂直于线的方向按一个点处理。需要“线段等距采样”，所以要完整记录。

## 载荷的精度

换能器的载荷按单元的基函数精确积分，不依赖网格线落在条带或传力区的什么位置（[`spectral3d/loads.py`](../spectral3d/loads.py)）。圆片的径向牵引不是两个方向函数的乘积，仍用节点求积，传力区内要有足够的节点。

## 限制

- 没有压电耦合、楔块里的多次反射、耦合层和胶层。
- 换能器只能放在坐标平面的面上（板的上下表面或端面）。
- 四面体求解器不支持这两种分布；二维平面应变求解器支持宽度为 0 的斜楔和条形压电片。
- 接收的频响（f 与 2f 处灵敏度之比）不在模型里。
