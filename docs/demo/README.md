# 功能演示

[`WorkAI-1.5.0-功能演示.pdf`](WorkAI-1.5.0-功能演示.pdf)：把软件的每一项功能实际运行一遍的记录（49 页，2026-11-23）。16 次计算和 1 次参数扫描都是现场算的，截图未经修改。第 1 节回答“现在能不能用、结果可信到什么程度”，第 13 节列出演示中看到的问题和限制。

这个目录里的其余文件用来重做这份演示：

| 文件 | 作用 |
|---|---|
| `models.py` | 8 个演示模型的定义；写成软件能打开的模型文件，并可让运行中的软件逐个预检 |
| `compute.py` | 让运行中的软件逐个计算这些模型 |
| `lib.cjs` | 用 Playwright 驱动浏览器里的工作台并截图 |
| `stage_a.cjs` … `stage_d.cjs` | 四组截图：建模；界面里的计算、参数扫描、快速引擎、暂停继续、圆管、CFRP；非线性导波分析；其余模型的结果 |
| `report_shot.cjs` | 把导出的 HTML 报告渲染成图 |
| `content.py`、`build.py`、`pdf.cjs` | 文档的文字；把文字和截图排成 HTML；打印成 PDF |

命令见 PDF 的最后一节。需要约 1 小时、20 GB 磁盘；截图和计算记录不进仓库。

PDF 里的截图是 1.5.0 发布版的界面。演示中发现的界面问题（第 13 节）之后已在主分支改掉：结果页的视角按钮、色标范围、接触谐波的提示等。`lib.cjs` 和各 `stage_*.cjs` 按改过的界面写（例如用“侧视 XZ”按钮代替拖动），所以它们需要 1.5.0 之后的软件。

软件更新后重做演示时，`content.py` 里的数字（耗时、斜率等）要按新的截图核对一遍：它们是写在文字里的，不会自动更新。
