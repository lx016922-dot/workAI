# 材料阻尼

模型可以带材料阻尼。没有阻尼时，导波只因扩散变弱，二次谐波在相位匹配时一直线性增长；实际材料里 f 和 2f 处都有衰减，二次谐波先增后减。要把仿真与实验的幅值放在一起比，需要这一项。

核对报告：[research/material-damping](../research/material-damping/README.md)。

## 模型

整个物体的 Rayleigh 阻尼：

    m ü + (α m + β K) u̇ + f(u) = F

- α（1/s）：质量比例系数；β（s，界面上按 ns 填）：刚度比例系数。
- 任何模态在角频率 ω 处的幅值按 exp(−γt) 衰减，**γ(ω) = α/2 + βω²/2**，与是哪个模态无关。
- 沿传播方向，一个模态每米衰减 **γ / 群速度** 奈培（1 Np = 8.686 dB）。
- 损耗因子 η = 2γ/ω，品质因数 Q = 1/η。

两个系数能让**两个频率**处的衰减对上。做二次谐波时取 f 和 2f：这两处的衰减决定二次谐波能累积多远。其他频率处的衰减由公式给出，这是模型的性质，不是材料规律：只有 α 时各频率衰减率相同，只有 β 时按 ω² 增长。

## 怎么填

“模型开发器 → 材料与本构 → 材料阻尼”：

- 直接填 α 和 β；都填 0 就是无阻尼。
- 或者展开“由 f 和 2f 处实测的衰减换算”：填频率 f、f 处和 2f 处的衰减（Np/m 或 dB/m）以及这两个模态的群速度，点“写入 α、β”。
  - 群速度可以在一次无阻尼计算的结果页“频散与 f–k 谱”里查。
  - 只填 f 处的衰减时，按只有刚度比例项换算。
  - 2f 处的衰减率（衰减 × 群速度）需要在 f 处的 1 倍到 4 倍之间，否则这个模型给不出来，软件会说明。
- 填好后，下方列出 f 和 2f 处的衰减率、损耗因子、Q，以及纵波和横波的沿程衰减。

场景文件里是一个顶层字段：

```json
"damping": {"mass_per_s": 32000, "stiffness_s": 3.25e-9}
```

两个系数都可以放进参数扫描。

## 结果页

- **频散与 f–k 谱**：f 和 2f 处每个模态多一列“衰减 Np/m”。
- **沿程累积**：
  - 给出 A₁ 实测的沿程衰减（ln A₁ 对距离的直线拟合），与模型给出的那个模态的衰减对比。
  - 给出**扣除衰减后的 A₂/A₁² 斜率**：各点乘以 mX/(1 − e^{−mX})，m = a₂ − 2a₁，X 是从主激励算起的传播距离。相位匹配时，这是没有衰减的材料会给出的斜率。
  - 相位失配的模态对不做这个修正；拟合范围里有点不在主激励下游时也不做。
  - 这个修正只扣除累积的部分：离激励很近的地方还有一列不累积的二次谐波，修正后会偏高几个百分点（杆的核对里 60 mm 以外在 1% 以内）。拟合范围取远一些。

## 限制

- 刚度比例项（β > 0）需要“自动时间层”和冻结网络引擎；“训练时的时间层”和快速引擎只支持质量比例项，选了会在提交前说明。
- 阻尼很大（2f 处损耗因子超过 0.1）时会给出提示：波在几个波长内就衰减完，γ ≪ ω 的前提不成立。
- 非线性控制里，刚度比例项按切线刚度作用。
- 吸收层照常使用，它是只在层内加的质量比例阻尼，与材料阻尼相加。
- 二维平面应变求解器（源码里的 `spectral2d`）和四面体求解器不支持。

## 计算量

与无阻尼的同一模型基本相同：刚度比例阻尼力由相邻两层的单元消息外推得到，不需要额外的单元计算，时间层一般不变。多占两个与位移同样大的数组。阻尼很大时稳定极限下降，时间层会自动加密，提交前的“消息”窗口里能看到。
