# 图网络输入层：读取结论与 v2 输入设计

本文记录对冻结图网络（`graphwave`，离线软件 0.2.0 的预测引擎）输入层与训练流程的逐行阅读和数值核对，并给出支持任意信号、多源激励与更多边界条件的新版输入设计。本文不修改任何冻结文件；`offline/model/model.json` 中按哈希锁定的源码与权重保持原样。

## 1. 网络的数据流

一次预测是固定层数的递推，每一层对应一个时间子步。每层的计算为：

```
message  = Dᵀ · 能量网络( D · u )          # 图聚合 → 可学习求导滤波 → 能量激活 → 转置绑定散射
external = load · pulse[step]               # 激励通道
scaled   = (external − message) / mass · Δt²
u⁺       = u + w₀ (u − u⁻) + w₁ · scaled    # 可学习状态更新
u⁺[fixed] = 0
```

**输入（物理通道，不学习）**

| 输入 | 来源 | 现状 |
|---|---|---|
| 图结构：单元节点表、逆雅可比、体积权、集中质量 | `spectral3d.mesh` 的 GLL 六面体网格，含曲面孔 | 只有参数化板、管、通孔、缺口 |
| 载荷向量 `load[n,3]` | `spectral3d.mesh.boundary_data`：整面 GLL 积分的均匀牵引 × 方向 × 幅值 | 只能整面、均匀、单源 |
| 时间脉冲 `pulse[step]` | 短记录：`inference.source_values`；长记录：`signals.pulse_values` | 短记录只有 Hann；长记录有 Hann、高斯、矩形窗、线性扫频四种 |
| 固定节点 `fixed` | 整面全部节点、全部三个分量 | 无对称/反对称面，无吸收层 |
| 本构开关 `law` | 0 线性、1 StVK、2 Murnaghan | 三组控制都由同一组权重给出 |

**可学习参数**

| 部分 | 参数数 | 训练标签 |
|---|---|---|
| 单元内求导滤波器，3 阶与 4 阶 | 16 + 25 | Legendre 多项式在 GLL 节点上的解析导数 |
| 能量网络二次与三次系数 | 21 + 56 | 本构教师给出的二阶 Piola 应力，含 Murnaghan 二次项 |
| 状态更新权重 | 2 | 离散动量更新 |
| 续训：5 阶求导滤波器 | 36 | 同上，原 120 个参数逐位不变 |
| 长记录：三段时间组合权重 | 2 | 对称组合一致性与三阶局部误差抵消 |

训练只使用上述解析或本构标签，没有使用任何瞬态波场。

## 2. 数值核对：学到的参数与精确离散算子

用软件包内的冻结权重逐项对比：

| 部分 | 对照的精确算子 | 最大差异 |
|---|---|---|
| 3 阶求导滤波器 | GLL 求导矩阵 | 1.8e-15 |
| 4 阶求导滤波器 | GLL 求导矩阵 | 2.5e-8 |
| 5 阶求导滤波器 | GLL 求导矩阵 | 2.5e-14 |
| 状态更新权重 | 中心差分 [1, 1] | 0 |
| 能量网络二次系数 | 该铝材料的各向同性弹性张量 | 相对 8.3e-16 |
| 能量网络三次系数 | Murnaghan 二阶应力项 | 相对 1.9e-15 |
| 时间组合权重 | 四阶 Yoshida 组合系数 | 2.2e-16 |

再把网络预测与仓库内的谱元显式求解器放在同一网格、同一时间步上对比。算例是 10 × 3 × 2 mm 铝板，3 阶，1750 个节点，0.2 MHz 两周期 Hann 脉冲，记录 14 μs：

| 量 | 结果 |
|---|---|
| 每个输出采样的递推层数 / 求解器子步数 | 7 / 7 |
| Murnaghan 全场最大差 | 1.5e-14 m |
| 全场最大位移 | 1.5e-7 m |
| 相对差 | 1.0e-7 |

**结论。** 这个图网络的结构是可学习的离散算子：可学习滤波、能量网络、转置绑定的消息与可学习状态更新。但训练把每个参数都收敛到了精确值，所以冻结网络在数值上就是 GLL 谱元中心差分格式加 Murnaghan 本构。由此可以推出三点：

- 原评估中对更细网格的 0.438% 全场误差，是这套离散本身的离散误差。
- 递推层数不少于谱元求解器的子步数，推理成本与数值求解同阶。网络的时间步上限按 10000 m/s 取，同一 CFL 下层数约为求解器的 1.5 倍。
- 激励只从 `external` 通道进入。学到的参数与激励、信号无关，扩展激励不需要重新训练。

仓库中真正从瞬态数据学习的模型，都没有通过全部 5% 验收门槛：坐标神经场的完整场误差 51%–95%、材料增量 56%–214%，谱算子完整场 95%–107%，物理约束场网络 13%–75%。模态能量模型的场误差通过，但动量残差未通过。详见 `docs/operator-training-3d.md`、`docs/spectral-operator.md`、`docs/physics-training.md`、`docs/modal-energy-training.md`。

## 3. 「任意信号、任意激励、边界条件」对这个网络意味着什么

| 需求 | 是否需要学习 | 做法 |
|---|---|---|
| 任意信号 | 不需要 | 脉冲通道改为调用 `physics.signals.evaluate`，支持全部 v2 信号与用户采样 |
| 多源与空间分布 | 不需要 | 外力改为多通道求和 Σₖ loadₖ · sₖ(t)，loadₖ 由 `spectral3d.loads` 的 v2 面载荷积分给出 |
| 固定、对称、反对称面 | 不需要 | 整节点固定改为按分量的约束掩码 `mask[n,3]`，取自 `physics.boundaries.build_constraints` |
| 吸收层 | 不需要 | 新增阻尼场 α[n] 物理输入，状态更新改为下式 |
| 其他材料 | 需要重新蒸馏，或改为材料输入 | 能量系数是 λ、μ、l、m、n 的线性函数；可按原流程对新材料重新拟合，或学习一个从材料参数到系数的线性层 |
| 任意 CAD 几何 | 需要新的图结构 | 当前图来自参数化 GLL 六面体网格；任意 CAD 需要六面体划分或适配四面体的图，是独立的大项目 |

带吸收层的状态更新，对应质量比例阻尼 m ü + m α u̇ = f 的中心差分：

```
c₁ = (1 − αΔt/2) / (1 + αΔt/2)
c₂ = 1 / (1 + αΔt/2)
u⁺ = u + c₁ · w₀ (u − u⁻) + c₂ · w₁ · scaled
```

α = 0 时退回原式。能量记录需要增加耗散列，收支检查改为「动能 + 势能 + 耗散 = 外力功」。

## 4. v2 输入层设计

**位置与兼容。** 新建独立包，不改 `graphwave` 下任何文件。复用冻结权重，权重哈希不变；新清单记录输入层源码哈希与所用权重哈希。版本 1 场景经新输入层得到的结果必须与原冻结路径逐位相同，或差异不超过 1e-12 并说明来源。

**输入张量**

| 名称 | 形状 | 内容 |
|---|---|---|
| 图结构 | 同现有 | 单元节点表、逆雅可比、体积权、质量；直接网格与曲面孔网格都支持 |
| `loads` | K × n × 3 | 每个源的节点载荷，主源加最多 15 个附加源，支持均匀、高斯、梳状分布与圆盘区域 |
| `signals` | K × 层数 | 每个源在每一层时刻的信号值；长记录在三段组合的各级时刻求值 |
| `mask` | n × 3 | 真值表示该分量被约束，与 `physics.boundaries` 一致；固定面约束三个分量，对称面只约束法向分量，反对称面约束两个切向分量 |
| `alpha` | n | 吸收层阻尼，线性、二次或三次斜坡；没有吸收层时为空，走原更新式 |
| `law` | 标量 | 不变 |

**仍然保留的物理守卫。** 应变上限 1e-3、J > 0、能量有限；能量收支 1% 检查，含耗散；接收点越出实体时拒绝。

**适用范围声明。** 激励扩展不改变网络参数，但需要新的有效范围声明：

- 网格要能解析激励的最高频率成分。按信号的 30 dB 带宽上限检查 2f 剪切波长内的节点数。
- 材料仍限定为原训练使用的多晶铝，直到完成重新蒸馏。
- 几何仍限定为参数化板、管、通孔、缺口。

**验收**

1. 版本 1 场景：与原冻结路径一致。
2. v2 场景：与 `spectral3d` 的 v2 求解在同网格、同时间步上一致，覆盖多源、梳状、对称面、吸收层四类。因为算子相同，预期差异在 1e-10 量级。
3. 精度声明：对每类新激励，用 `sweep converge` 做网格加密、阶次提升、时间步减半复核，以复核结果报告误差，不用网络与求解器的一致性代替精度。

## 5. 需要决定的方向

**A. 只扩展输入层。** 工作量小，结果可靠，任意信号、多源、对称面、吸收层可以直接用于离线软件。代价是这条路径在数值上仍然等同谱元求解，不带来提速，也谈不上数据驱动的学习。

**B. 在 A 的基础上，训练粗网格算子。** 保留现有结构约束：转置绑定的能量消息保证能量守恒，求导滤波器消去刚体平移。用经收敛复核的细网格参考解作标签，训练滤波器、能量系数、质量与时间权重，让更粗的图、更大的时间步复现细网格的波形和 2f。这才是 AI 真正增加价值的地方，即用更少的节点和层数得到同样精度。风险是超出训练频带和几何范围时精度下降，必须在留出工况上按 5% 门槛验收。它与以往失败的全局神经场不同：学习对象仍是局部算子，激励和边界仍通过物理通道进入。

建议先做 A：B 也需要它，而且 A 可以马上让离线软件支持新的激励与边界。然后按明确的验收门槛开展 B。
