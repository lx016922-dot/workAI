# 高阶参考场与共享物理约束网络

本轮将参数化铝板、圆管、通孔板和贯穿宽度的矩形缺口接入同一套高阶参考计算与网络训练流程。模型仍为实验性模型；是否完成训练、测试误差和数值验收结果以保留的清单为准。`accepted_for_solver_routing` 始终为 `false`，本轮不会自动替换已有求解器。

## 数值参考

`spectral3d/curved_mesh.py` 生成相容的等参 GLL 六面体。圆管使用轴向、径向和周向坐标，孔板使用连接孔边与矩形外边界的 O 型网格。坐标和位移使用相同形函数；物理梯度乘几何雅可比的逆。曲面边界本身也是多项式近似，纳入网格和阶次检查。

`spectral3d/curved_solver.py` 对完整 Murnaghan / StVK / 线性控制计算第一 Piola 应力、内力和离散能量。各控制使用相同网格、激励、边界和时间采样。保留全三分量双精度场。

显式积分继续使用速度 Verlet 和实际最小节点间距 CFL。小孔附近的细小单元会限制显式时间步，故另提供 `implicit.py` 的 Newmark 平均加速度法（β=1/4，γ=1/2）。隐式法对完整非线性方程迭代；线性刚度仅作为修正 Newton 的预条件矩阵。没有阻尼、质量缩放、模态截断或学习修正。v2 使用对称排序 LU，并利用质量归一化正定系统的残差上界，在已经满足同一 Newton 容差时省去重复线性求解；不改变本构、积分或容差。完整带孔算例对照中，完整场差异约 2.83e-14、材料增量场差异约 5.05e-10（相对 RMS）。收敛容差为 `1e-20 + 1e-11 * max(abs(u))` m，最多 8 次迭代，未收敛即终止。

材料沿用已记录的铝参数及 Murnaghan 定义，见 [aluminum-material.md](aluminum-material.md)。该多项式超弹性能量仅在本项目应变范数 ≤0.001、J>0 的范围研究；不构成塑性、接触或任意大变形模型。

## 新几何与参考场准入

`dataset.py` 的固定种子为 2026102311；16 个新几何按 8/4/4 分为训练、验证和最终测试。每个形状家族有两个训练、一个验证和一个测试几何。实际几何的规范化身份不包含无关参数，并与过去 64 个几何核对无重复。所有材料控制和网格重复属于同一几何组，不能作为新增独立样本。

本批范围：长度 8–12 mm，板宽 3–4 mm、厚 1.5–2.1 mm；管外半径 2.2–2.8 mm、壁厚 0.85–1.1 mm；孔半径 0.55–0.8 mm。完整轴向端面加载，可包含横向牵引分量；对端自由或固定。幅度 0.6–1.5 MPa，载频 0.18–0.28 MHz，1.5–2.1 周期 Hann 包络，14 μs 记录、0.05 μs 输出。此采样范围并非已获得全范围准确率保证。

最初每个几何安排 p3/h2 基准、p3/h1.4 网格细化、p4/h2 阶次细化和同网格时间细化（显式减半 CFL 上限，隐式将子步数加倍），共 12 次完整控制计算。固定准入规则同时检查两个接收点的 XYZ 和请求方向、完整位移和材料增量、材料 2f 复数系数，以及所有保存帧在较细网格节点处的质量加权全场差异。阈值为 5%；报告下限为 1e-13 m，低于下限只检查绝对差异，不给出相对精度证书。能量收支、应变及 J 同时检查。

粗网格检查失败时，`admit.py` 保留所有旧结果并补算。板、管和缺口先以 p3/h1.4 为基准，用 p3/h1、p4/h1.4 和减小时间步核验；仍失败则以 p4/h1.4 为基准，用 p4/h1、p5/h1.4 和减小时间步核验。孔板优先检查节点较少的 p4/h2，使用 p4/h1.4、p5/h2 和同网格加倍子步数验证；失败才转入 p4/h1.4 的同一后备规则。任何阈值都不放宽。

高阶计算中的线性代数优化另做三控制完整对照，通过后转入 `aluminum16-20261023-v2` 准入目录；两个在途高阶等级保留为中断记录，在新目录重算。最终 `aluminum16-20261023-v3` 使用上述孔板升阶优先规则，并校验摘要后复用已有完整等级；已启动的旧等级先正常完成，再停止旧调度器。每次准入重新计算误差，不能仅凭旧的通过标志放行。原始数据、已完成场和历史检查均保留。

曲面网格的边界多项式不同，少量较细边界节点可能在粗多项式边界之外。只有全场比较允许参考坐标超出 ≤0.002 的小范围外推，并记录节点数；用户点位提取始终严格拒绝实体外、管腔和孔洞，不使用这一外推许可。首次比较的 Newton 反解停止精度与坐标重构断言不一致，导致原清单保留失败状态；后续独立准入清单用更严格的反解精度重做比较，原始求解结果未改写。

这些准入检查涵盖完整场和材料增量的离散差异，不能证明连续域任意点、任意投影的相对误差，也不构成单一导波模态的累积性证明。2f 使用全记录 Hann 窗复数系数，包含反射。

## 网络与物理约束

`spectralop` 使用共享几何条件网络，输入几何边界、加载/固定区域、激励和空间时间坐标，输出三组 XYZ 位移：线性、StVK−线性、Murnaghan−StVK。输入不含有限元响应或拟合的测试模态。

物理约束与生成标签的高阶离散一致。对每个抽样节点，收集并组装**全部**相邻单元，以相同 GLL 积分、几何映射、实际节点质量和牵引计算弱动量残差；不会将高阶标签送入历史四面体残差。内部节点和自然边界节点分别计分。时间二阶差分间隔为 0.025 μs。训练每步抽取 3 个内部节点、1 个加载面节点和 1 个自由表面节点；这属于抽样软约束，并非全域精确满足 PDE。

激励前零位移、零速度及固定边界零位移由模型结构保证；小应变和正 J 用软惩罚及评估检查。归一化只使用训练工况。验证集的场误差与固定权重物理残差用于选取权重。选定权重写入 SHA-256 冻结记录并精确重载核对后，训练进程才读取最终测试响应。数值参考质量检查按预先固定的规则运行，可检查测试标签精度，但不根据网络测试预测调参。

最终测试检查所有保存时刻、所有参考节点的质量加权场误差和 XYZ 分量；两个接收点的完整/材料波形及复数 2f；另在五个固定种子随机时刻抽样弱平衡、应变和 J。抽样物理通过不代表未采样时空处也通过。即使本批门槛通过，代理路由仍需单独评审，本轮不会启用。

## 重现与使用

现有结果位于 `/workspace/workai-remote/spectral3d`，训练位于 `/workspace/workai-remote/spectralop`。每次求解、准入和训练均保留输入、源文件快照及 SHA-256；新输出目录必须不存在，历史结果不覆盖。重新打开结果不得自动生成数据或训练。

求解环境：`/workspace/workai-remote/solid/venv/bin/python`（NumBa、NumPy、SciPy）。训练环境：`/workspace/workai-remote/training/venv/bin/python`（CPU Torch、NumPy、SciPy）。训练模块不要求导入 NumBa。并行求解限定每个进程 BLAS/OMP 为 1，训练使用两个 Torch 线程。

```bash
# 仅运行物理单元检查，不进行新训练或瞬态求解
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /workspace/workai-remote/solid/venv/bin/python -m unittest spectral3d.test_physics spectral3d.test_curved spectral3d.test_implicit solid.test_physics
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /workspace/workai-remote/training/venv/bin/python -m unittest spectralop.test_physics
npm test
```

独立核对包括 NumBa 求解器和 Torch 高阶残差的三组节点力、离散能量梯度、刚体旋转、仿射梯度、完整节点组装、初始/固定条件、重复几何隔离。浏览器检查高阶曲面反解、完整场和材料增量动画、任意非零方向 CSV、NumPy FFT、空域拒绝及移动布局。

`tools/export-spectral-result.py` 从已完成的高阶场生成单文件动画；`tools/export-training-report.mjs` 生成训练记录；`tools/export-operator-comparison.py` 导出测试点位的交互对比。这些工具只读取已保存结果。源代码 ZIP 不包含权重、场数据或配对身份；发布环境应保留整个工作目录和运行数据。

## 本轮实际结果

2026-10-23 完成 374 次高阶参考控制计算，另保留 2 次中断控制；这些包含网格、阶次和时间步重复，以及已消耗开发例，不代表 374 个独立几何。16 个新几何全部通过准入。共享网络实际完成 8000 个优化步，验证集选中第 1700 步权重；冻结摘要为 `ef27a4f71d43e81cd249ee73f266a91ab80f161b7d50878639f401fa91cac8ba`。

最终独立测试的完整场相对 L2 为：板 100.21%、管 106.72%、孔板 104.52%、缺口 95.19%；材料增量分别为 80.08%、113.15%、109.02%、70.53%。场、接收点/2f 和抽样弱平衡均未通过 5% 门槛。应变及正 J 检查通过。参考数据精度改进没有使本轮网络获得可靠泛化能力，代理路由继续关闭；这四个测试几何现已被评估，今后只能作为开发集，不能再次宣称全新测试。

独立重放核对了全部来源和数据摘要、四个测试工况的 48 项场指标、8 个点位的数组/波形/复数谐波，并从冻结权重逐值重算一个完整测试场。浏览器核对了真实训练页面、离线报告、交互 AI/有限元对照，以及管/孔板的完整场和材料增量动画。

## 在工作台提交新工况

“ 三维超弹性研究 ”的求解方式现可选择高阶计算。输入板、管、通孔或缺口参数后，选择 3 / 4 阶单元，设置完整 X 端面牵引（孔径半径 0）；另一 X 端面可固定，也可全自由。圆管与孔板使用等参曲面网格；孔板使用完整非线性 Newmark，其余使用 Verlet。计算实际三分量位移场，结果页按相同高阶形函数提取新点位及任意非零方向的波形、频谱与 CSV。

网格尺寸输入表示高阶单元的尺寸参数；初始波长筛选使用 h/p（不小于原验证器的 0.02 mm 下限）估算自由度间隔，这只是初筛，不能替代实际网格与阶次收敛验证。每个新任务单独保存参数、阶次、代码快照、网格、双精度场和摘要。接口与已有计算共享会话、同源检查及任务互斥；打开结果不触发新计算。限制为 30000 节点、100000 个单元积分节点、50000 个显示三角形、192 MiB 未压缩场和 30 分钟计算预算。超限应调整网格尺寸或记录时长。CAD、局部曲面加载和页面内的五组非线性对照研究继续使用原四面体选项；高阶交互模式当前提交单次指定本构计算。

这是实际高阶数值求解，不是已验收的 AI 推理。交互任务没有自动完成 h/p/时间步对照，界面明确显示“数值精度待独立验证”；它们不继承这 16 个训练参考几何的验收。原四面体任务及其结果保持可读。

四类结构均已从真实页面提交一次带横向分量的新激励，完成 4 个单控制交互计算。这 4 个功能检查不参与上述训练，也不计入 374 次参考控制。浏览器导出的 XYZ、任意方向投影和频谱与保存场及独立 NumPy 结果一致，原四面体结果仍可读取，桌面/移动布局无溢出。新增接口测试后，84 项 Node 检查全部通过。
