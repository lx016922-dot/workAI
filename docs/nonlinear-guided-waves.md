## 需要落到场景和模型中的物理条件

### 1. 先确定导波模态及线性基线

对同一厚度、材料、边界和频率确定传播模态与振型，记录波数、相速度、群速度及其单位。仅知道频率不等于已经选择 S0/A0/SH 等模态。在适用的各向同性均匀自由板范围内，可用 Rayleigh–Lamb/SH 结果建立线性基线；其他结构需使用与结构相符的频散模型。

### 2. 区分材料、几何和接触非线性

一种有限应变弹性表述是以 Green–Lagrange 应变 E 定义应变能密度：

```text
E = (Fᵀ F − I) / 2
W(E) = ½ C⁽²⁾ᵢⱼₖₗ Eᵢⱼ Eₖₗ + ⅙ C⁽³⁾ᵢⱼₖₗₘₙ Eᵢⱼ Eₖₗ Eₘₙ + …
S = ∂W/∂E,  P = F S,  ρ₀ ü = Div P + b₀
```

采用一致的参考构形：F 为变形梯度；S 为第二 Piola–Kirchhoff 应力；P 为第一 Piola–Kirchhoff 应力；ρ₀ 为参考密度，b₀ 为单位参考体积的体力。重复指标求和，W 为单位参考体积能量。以上是可供核对的一种约定，须以原模型实际实现为准。

- 三阶常数的张量/Voigt 约定、单位及 Murnaghan/Landau 定义必须记录，不能直接交换数值。
- 三阶常数置零不必然消除有限应变带来的几何非线性。线性对照须同时采用相应线性化运动学和应力关系。
- 不从纵横波速度反推出缺失的三阶常数；未获得实验或可信来源参数时留空。
- 接触非线性还需接触面、间隙、预载荷、法向定律、必要时的摩擦和耗散参数。自由表面开口缺口不等同于呼吸裂纹。

### 3. 二次谐波与累积

对指定基频模态 m 和二次谐波模态 n，定义相位失配：

```text
Δk = kₙ(2ω) − 2 kₘ(ω)
```

持续累积需要足够小的相位失配和非零的模态耦合；仅比较相速度还不够，需检查振型对称性及耦合积分。

在弱非线性、单一模态对、无损耗、基频未明显耗尽且无入射二次谐波的近似下：

```text
|A₂(x)| ∝ |κ| |A₁|² x |sinc(Δk x / 2)|,  sinc(z) = sin(z) / z
```

κ 的定义随模态归一化和本构约定变化。Δk → 0 时才得到该近似下的线性距离累积；有衰减、失配、反射、泵浦耗尽或多模态耦合时应使用相应模型。不能在所有场景中硬编码 A₂ ∝ x。

有限脉冲还需足够的波包重叠，可用传播后的群延迟差 `x |1/cg₂ − 1/cg₁|` 与有效脉冲时长 τ 比较。相位匹配与群速度匹配是不同条件。

### 4. 和频、差频及调制

检查 `ω₃ = ω₁ + ω₂` 或 `ω₃ = |ω₁ − ω₂|`，同时使用含方向的波矢关系、非零模态耦合和时空重叠条件。差频的传播方向不能由频率绝对值直接决定。

弱二次耦合下产物幅度的 A₁A₂ 标度只能在其近似条件内检验。多频线性激励本身不产生新的混频成分；次谐波和接触调制不能用材料二次谐波公式代替。

### 5. 谐波提取及相对指标

从同一次激励响应中提取基频与产生的谐波，记录位移/速度/应力/电压等信号量、幅值约定、单位、接收分量、位置、时间窗、窗函数、频带与模态分离方法。

`|A₂|/|A₁|²` 一般带有幅值倒数的单位；只有明确归一化、传播长度、频率、模态和仪器校准后，才可讨论其与绝对材料非线性参数的关系。不同观测量、传播距离或模式下的该比值不可直接比较。

控制源自身谐波、换能器/接收链非线性、频谱泄漏、反射重叠和数值误差。二次幅值标度本身不能唯一识别非线性机理。

**当前连接验证任务在 3 MHz 和 6 MHz 分别求解反射/透射。它们不是同一激励的 A₁、A₂，禁止用其比值报告非线性系数。**

## 恢复模型后的验收顺序

1. 将收到的研究源码与已签名摘要比较，阅读本构、几何、源、接触设置、任务协议和输出定义；差异需查明版本，不通过改摘要消除差异。
2. 建立适用的线性基线，核对模态和频散；建立相同参数的非线性关闭对照。
3. 在相应弱非线性范围内检验幅值标度、距离累积与失配效应；混频加入单源对照；接触模型验证开闭及接触参数敏感性。
4. 对最高关注谐波的最短波长与周期分别做空间、时间离散收敛，单独考察小幅谐波的幅值与相位误差。基频占优的整段波形 L2 小，不能证明弱二次谐波准确。
5. 明确边界反射、材料损耗、模式间能量转移的影响，使用包含这些项的能量平衡。不要把基频能量变化都当成误差，或把线性互易性判据直接套用于任意非线性受泵状态。
6. 与独立解析/半解析或收敛数值解对比，再对实验；原规划的误差阈值是建议，不是已经接受的非线性谐波验收标准。
7. AI 加速必须另有实际权重、训练覆盖范围及分布内/外误差证据。PDE 残差小或健康接口成功均不证明与 COMSOL 等精度。
