## 物理模型的明确结论

**这份源码实现线性弹性，没有材料三阶本构。** 判断来自实际弱式方程和输入协议，而不只是源码开头的注释：

| 位置 | 实际内容 | 结论 |
| --- | --- | --- |
| UltraResearch.java 第 72–73 行 | `μ = ρ cT²`，`λ = ρ(cL² − 2cT²)` | 只有二阶各向同性弹性参数 |
| 第 95–104 行 | 位移梯度的一次项乘检验函数；惯性项为 ρü | 小应变线性 P–SV / SH 弱式，无 Green–Lagrange 二次运动学或三阶材料应力项 |
| 第 100–102 行 | 可选线性导热和单向热应力 | 不是材料非线性模型 |
| 第 62–67 行 | 给定频率的 Hann 包络正弦脉冲相加 | 用户输入两个频率不代表模型产生了非线性混频 |
| 第 106–125、165–166 行 | `active_tx` 逐个选择激励并分别求解 | 多个 shot 是独立激励，不能当成同时激励的混频研究 |
| 第 79–84 行 | 几何减去矩形开口缺口 | 没有裂纹接触定律、开闭或预载荷 |
| Research.Common.ps1 第 11–25 行 | 严格允许列表仅接受已定义数值参数 | 没有 l/m/n、A/B/C 或非线性开关，新增三阶参数会被拒绝 |

所以本次只把它作为材料非线性研究的**线性对照基础**。源的有限带宽、数值误差或多频输入可能在 2f 附近出现成分，不能据此声称发生了材料非线性频率转换。
