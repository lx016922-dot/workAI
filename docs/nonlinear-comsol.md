# 铝薄板材料非线性 COMSOL 实现与验证

2026-10-22。此实现是在已恢复线性研究源码上新增的版本，不是声称已取得原网站的非线性源码。材料来源和能量约定见[铝材料记录](aluminum-material.md)。

## 计算模型

`server/comsol/UltraResearch.java` 保留原线性分支，并新增 `workai.murnaghan.guided_plate.scene.v1` 场景。原导出源码位于工作区外的不可变目录，没有改写。`tools/build-nonlinear-model.py` 可从摘要固定的原文件重建此 Java 版本，`server/comsol/model.json` 固定新源码摘要。

二维参考坐标为 X、Y，Z 方向不变。位移有 u、v、w 三分量，变形梯度为：

```text
F = [[1+u,X,   u,Y,  0],
     [  v,X, 1+v,Y,  0],
     [  w,X,   w,Y,  1]]
E = (FᵀF − I)/2
S = [λ tr E + B tr(E²) + C(tr E)²]I + [2μ + 2B tr E]E + A E²
P = F S
A = n, B = m − n/2, C = l − m + n/2
```

弱式为 `∫Ω [ρ₀ ü·δu + P:∇Xδu] dΩ − ∫Γ T₀·δu dΓ = 0`。使用参考密度、参考面积上的名义牵引及第一 Piola 应力，不混用 Cauchy/第二 Piola 应力。无材料耗散、塑性或裂纹接触。

左端面施加沿 X 的均匀、单载频、Hann 包络脉冲。其余边界自由，没有人为施加 2f 分量。模型以对称的伸缩激励研究 S0 候选响应，但没有作模态投影。Z 为平面应变；该路径不能独立识别所有三阶常数，特别是 w=0 时 det(E)=0，不能借此标定 Murnaghan n。

每个任务有五个独立对照，CSV 的 `shot` 固定对应：

| shot | 本构 | 名义牵引幅值 |
| --- | --- | --- |
| 0 | 小应变线性 Hooke | A |
| 1 | 完整 E、P=FS，三阶能量项为零 | A |
| 2 | 完整 E、P=FS，Murnaghan 三阶能量 | A |
| 3 | 同 shot 1 | 2A |
| 4 | 同 shot 2 | 2A |

同一套对照分别使用粗网格、细网格、细网格且内部时间步减半，共 15 次真实求解。四阶单元，二十阶空间积分；三阶 Green 应变能的弱式在四阶位移插值下最高多项式次数为 18，原线性八阶积分不直接沿用。时间积分为手动 generalized-alpha、ρ∞=1，无算法高频耗散；更小时间步仍需检验相位误差。

每次求解检查所有输出时刻的全域最大 Green 应变范数及最小 J；要求 `||E||F ≤ 0.001` 和 `J>0`。这是计算预算，不是已测得的铝弹性极限，也不是所有内部时刻的连续证明。A 扫和场 CSV 导出后清除解，保存 MPH 并重新打开检查配置。

## 输入和可追溯性

新场景有显式 `nonlinear` 常数字段、能量定义和对照列表，材料卡 ID/摘要及用途也进入场景。**不使用热学或其他不相关参数位置传递三阶常数。** 原数值参数只传输已有的几何、二阶常数、激励与离散信息，继续通过原 PowerShell 允许列表。

Java 在求解前解析已签名的 `request.json`，拒绝重复键、非有限数值、错误字段和嵌套超限；重新检查场景/参数 SHA-256，按新场景重建预期数值字段，逐项对照 `parameters_json` 与 `case.properties`。已冻结材料卡的定义和数值在云端与 Java 两端均核对。未知字段或错误单位不会默认为线性求解。

回执写明实际方法、本构、材料卡、五组顺序、常数、积分阶次、每组应变/J 检查、网格和时间步。读取结果时逐项核对，并验证文件签名、摘要、行数和时间网格。每类 CSV 五组总计最多 4000 行，适配现有 1 MiB 下载器。保存的普通网页不提供任意 Java 上传接口；本次维护更新走已配对的签名 revision 接口，先编译、备份旧版再替换。

## 二次谐波分析

`server/physics/harmonics.mjs` 从二维自由板 Rayleigh–Lamb 对称色散式求 S0 候选的波数和群速度，限制 `f·d ≤ 1.2 MHz·mm` 且指定相速度区间内只有一个根。基频和 2f 任一不满足时，不报告此分析指标。

每个接收位置使用同长度、随预测基频群速度平移的 Hann 窗：起点为 `delay + x/cg(f) − 0.5/f`，终点为 `delay + x/cg(f) + (cycles+0.5)/f`。窗口必须完整落在输出记录中。计算加窗均值后去除均值，再作指定 f/2f 的复数投影，幅值归一化为 `2/sum(window)`。这是定义明确的有限脉冲相对幅值，不是稳态单模态幅值的通用校准。

- 基频 A₁：shot 2 的 u 分量在 f 的投影。
- 线性背景：shot 0 在 2f 的投影。
- 几何增量：先在时域作 shot 1 − shot 0，再提取 2f。
- 材料增量：先在时域作 shot 2 − shot 1，再提取 2f。不能相减两个幅值的绝对值。
- 双幅值材料增量：shot 4 − shot 3，与基准材料增量比较，弱二次机制预期幅值比接近 4。
- 网格/时间步差异：比较材料增量的复数系数，保留幅值和相位误差。相对差异分母为较细参考系数的模；为零时未定义。

页面以网格差异 ≤5%、时间步差异 ≤5%、双幅值比相对 4 的偏差 ≤5% 为当前算例检查阈值。通过这些检查不代表绝对误差或所有工况精度达到 5%。窗口不完整、分量为零或检查未过时保留明确状态，不伪造通过标记。

沿距离的材料增量可用于检查有限区间增长；应同时查看 `Δk=k(2ω)−2k(ω)`、相干长度 `π/|Δk|`、群延迟差以及边界回波。A₂/A₁² 的单位为 m⁻¹，未作材料绝对非线性系数反演。

## 验证与适用范围

自动检查涵盖三维本构能量梯度、刚体转动、小应变极限、三阶常数约定；新场景身份和单位拒绝、五组映射、全部 15 次应变回执、S0 低频极限与独立 SciPy 根、复数谐波幅相、背景扣除及二次幅值标度。浏览器检查覆盖新模板保存/重载/导出、无效幅值保护、十五次求解提示、手机布局，并禁止测试触发计算。已有真实线性任务仍可读取。

本 COMSOL 实现没有实验标定、模态投影、模式耦合积分、完整能量平衡、材料衰减或不确定度传播。它为有出处的铝参考材料建立可追溯的非线性导波计算和数值对照流程。另已启动[物理约束代理模型训练](physics-training.md)，首轮尚未通过精度验收，未用于替代这里的真实求解。
