# 三维铝结构：超弹性求解、动画和任意方向接收点

工作台侧栏新增「三维超弹性」。现已跑通：几何和激励输入 → 实际四面体网格 → 三维瞬态求解 → 位移场动画 → 任意实体内点位、任意方向的波形与频谱。该模块使用本云环境的 CPU 有限元计算，不调用远程 COMSOL，也未启用神经网络代理。

## 使用

1. 选择参数化板、管、带通孔板或带表面缺口板，填写尺寸，单位为 mm。管轴为 X 轴；孔沿 Z 方向贯通；缺口从板的 Z 上表面切入、贯穿 Y 宽度。
2. 也可上传一个封闭实体的 STEP/STL（最多 8 MiB）。STEP 按文件单位转换为 mm；STL 需指定单位。检查导入包围盒、接收点和激励区域。装配体、开放曲面、非流形 STL 或无法网格化的文件会报错，不自动补齐孔口。
3. 选择 Murnaghan 超弹性、StVK 有限应变或线性对照。设置 Hann 包络正弦牵引的幅值、频率、周期数、延迟和相位。默认 Murnaghan，0.2 MHz、2 周期、1 MPa。
4. 激励可施加在坐标端面，或用中心、半径及外法向选择表面局部区域。载荷方向是独立的全局向量，会归一化；曲面法向用于选择面片。实际加载面积由网格表面三角形计算并记录。未固定的其余边界为自由边界。
5. 设置采样时长、输出间隔和网格尺寸，填写初始接收点，启动真实计算。完成后拖动旋转、播放或拖动时间帧；动画颜色对应实际位移，形变显示倍率单独标注。
6. 结果页可继续输入任意实体内坐标和方向，无须重新求解。四面体内线性插值保留完整三分量；显示有符号投影 **u·n**。孔内、管腔或缺口内的点会被拒绝，不吸附到附近实体。频谱使用 Hann 窗、去加权均值和单边幅值归一化，可调整显示上限并下载 CSV。

当前支持一个固定面或全部自由；尚无接触、塑性、压电换能器、吸收层或任意波形文件。曲面载荷区域按三角形中心选择，边缘精度随网格变化。任意点指实际离散实体内部；曲面在四面体网格中是分片平面近似。

## 物理定义与适用范围

固定材料卡为多晶铝文献参考：ρ = 2700 kg/m³，λ = 58.1、μ = 26.1、l = −143、m = −297、n = −345 GPa。来源及常数约定见[铝材料说明](aluminum-material.md)。这不是特定铝合金牌号、试样或温度的标定。

求解器使用总拉格朗日描述、线性四面体、集中质量和显式速度 Verlet。计算采用 float64；普通计算输出 float32 并记录转换误差，新增[五组材料非线性对照](solid-harmonics.md)保留 float64 完整场。定义 F = I + ∇u、E = (FᵀF − I)/2，

```text
W = λ/2 (tr E)² + μ tr(E²)
    + A/3 tr(E³) + B tr(E) tr(E²) + C/3 (tr E)³
A = n, B = m − n/2, C = l − m + n/2
P = F · ∂W/∂E
ρ₀ ü = Div P
```

源为参考构形上的固定方向名义牵引，不是随当前法向转动的压力。程序逐内部时间步检查所有单元的 J 和应变；J ≤ 0 或 ‖E‖F > 0.001 会停止。这个应变限制用于限定三阶展开的使用范围，不等于经过实验验证的屈服判据。程序记录动能、应变能、外力功和能量收支；能量守恒本身不证明空间精度。

内部时间步依据实际最小四面体高度及波速选取。初始网格检查要求至少约 8 个目标单元覆盖剪切波二倍频波长，但它只是筛查，不能替代细化对照。默认资源上限为 40,000 个四面体、12,000 个节点、192 MiB 未压缩场、50,000 个内部步、3.5 亿单元步和 30 分钟。超限会明确报错；大结构、高频或长记录通常需要更大的求解资源及专门的模型简化。

## 2026-10-22 实际计算证据

四个 12 mm 长的小型参考结构均完成真实求解；对同一物理场景作两级网格及同一网格上的时间步细化。下表为两个预设接收点中最大的三分量时域相对 L2 差异，方向投影也通过 5% 检查。

| 结构 | 网格尺寸 / mm | 空间与稳定步长联合差异 | 同网格时间步差异 |
| --- | --- | --- | --- |
| 板 | 0.50 → 0.35 | 0.3712% | 0.000924% |
| 管 | 0.50 → 0.35 | 1.3346% | 0.001053% |
| 通孔板 | 0.50 → 0.35 | 2.0304% | 0.000721% |
| 缺口板 | 0.35 → 0.25 | 3.7412% | 0.000245% |

缺口板初次 0.50 → 0.35 mm 对照差异达 7.34%，没有通过；保留失败记录后进一步细化。一次时间步试验因重新生成的网格不同，被排除出纯时间步比较；最终时间对照复用并逐项核对同一网格。

**这些数字仅覆盖列出的参考场景和接收点，不是全域误差上界，也不是任意新结构的精度保证。** 尚未对该三维求解器完成独立 COMSOL 或实验对标，也未证明二次谐波的全场/模态误差小于 5%。新接收点、激励、几何及材料需要相应核对。二维非线性 COMSOL 的既有验证单独保留，不能移用为三维证明。

还从本地生成的 L 形支架分别导入 STEP/STL 并完成求解，验证切除区域没有被填充。浏览器验收实际执行一次 STEP 上传、局部表面激励、启动计算、动画及 Z 向波形/频谱提取；这只验证流程，不是独立精度对标。

## 安装、结果与训练状态

```sh
bash solid/prepare-solid.sh
npm start
# 仅导出已完成任务，不启动计算；输出文件必须尚不存在
node tools/export-solid-result.mjs /workspace/workai-remote/solid/jobs/solid-ID new-result.html
```

依赖固定为 Gmsh 4.15.2、Numba 0.63.1、llvmlite 0.46.0；使用当前环境 NumPy 2.3.5 和 SciPy 1.17.0。准备脚本运行 7 项物理测试，不自动求解或训练。测试覆盖能量梯度、刚体转动、质量和内力平衡、独立半离散模态解、真实几何及空腔、对照约束、输出精度和输入约束。另有 67 项 Node 测试及真实浏览器检查。

运行状态保存在仓库外的 `solid/jobs`、`solid/assets` 和 `solid/venv`。网页重启不重发计算；当前仅允许一个活动任务。保持原有 COMSOL 私钥和连接配置，不需要重新配对。

独立结果 HTML 包含完整位移场，可离线旋转、播放并增加点位和方向，不会运行新的仿真。使用支持 WebCrypto、DecompressionStream 和 JavaScript 模块的近期浏览器。云端浏览器禁止 file://，验收以相同 HTML 的断网页面执行；未据此宣称测试过用户 Windows 的本地打开。
