Blaschke 的表 2 将 Al 三阶常数追溯到 Reddy 1976，经 Wasserbäch 1990 转引；本次直接读取的是 Blaschke 的公开全文，没有取得 Reddy 的原始实验数据。二阶和三阶常数是汇总表中的参考组合，密度来自另一来源，不声称整组来自同一批试样。原表的 ± 值予以保留，未把它当作已知置信水平、独立标准差或完整概率模型；没有据此生成虚假的置信区间。

机器可读材料卡：[`data/materials/aluminum-polycrystal-blaschke2017.json`](../data/materials/aluminum-polycrystal-blaschke2017.json)。内部统一使用 Pa；界面以 GPa 展示。材料记录保存了文献链接、表号、下载日期和原 PDF 的 SHA-256。`v1` 是固定参考版本；后续更换常数应创建新版本，保留已有场景引用的原记录。

由这组二阶常数和密度计算，而非另外拼接波速：

```text
cL = sqrt((λ + 2μ)/ρ₀) = 6391.54534145318 m/s
cT = sqrt(μ/ρ₀)        = 3109.126351029605 m/s
EYoung = μ(3λ + 2μ)/(λ + μ) = 70.20961995249407 GPa
ν = λ/[2(λ + μ)] = 0.34501187648456055
```

## 采用的本构定义

参考构形中的变形梯度和 Green–Lagrange 应变：

```text
F = I + ∇X u
E = (FᵀF − I)/2
i₁ = tr(E)
i₂ = ((tr E)² − tr(E²))/2
i₃ = det(E)

W = ½(λ + 2μ)i₁² − 2μi₂ + ⅓(l + 2m)i₁³ − 2mi₁i₂ + ni₃
```

W 是每单位参考体积的能量，单位 J/m³；这里 i₂ **不是** tr(E²)，i₃ **不是** tr(E³)。不使用工程剪切分量代替张量剪切分量。

等价的 Landau 形式为：

```text
A = n = −345 GPa
B = m − n/2 = −124.5 GPa
C = l − m + n/2 = −18.5 GPa

W = λ/2 (tr E)² + μ tr(E²)
    + A/3 tr(E³) + B tr(E)tr(E²) + C/3 (tr E)³

S = ∂W/∂E
  = [λ tr E + B tr(E²) + C(tr E)²] I
    + [2μ + 2B tr E] E + A E²
P = F S
σ = P Fᵀ / det(F)
```

总拉格朗日弱式中的内力使用 P 和参考坐标梯度，惯性使用参考密度 ρ₀。不能把 S 或 Cauchy 应力 σ 直接放进相同弱式而不作变换。现已按独立版本接入 COMSOL，使用显式材料字段和回执标识，见[实际模型与验收](nonlinear-comsol.md)。

### 三组对照

| 对照 | 运动学 / 本构 | 可用于区分什么 |
| --- | --- | --- |
| 线性 | ε = sym ∇u，σ = λ tr(ε)I + 2με | 激励带宽、线性传播和数值基线 |
| 几何非线性 | 完整 E、P=FS，三阶能量项关闭 | 有限应变二阶能的贡献 |
| 材料 + 几何非线性 | 完整 E、P=FS，保留三阶能量 | 与前两组比较材料三阶项的影响 |

三阶常数为零不等于完全线性。非线性解之间的差异也不能一般性地当作可叠加的独立波场。纯平面应变路径不足以独立识别所有三阶常数，因此本构核对包含三维应变路径。
