# 材料：自定义应变能密度（含 CFRP）

Murnaghan 模型只适用于各向同性材料。碳纤维复合材料（CFRP）等各向异性材料，需要直接写出材料的应变能密度 W(E)。仿真软件的“材料与本构”部分提供三种选择：

| 本构类型 | 适用 | 物理 AI 网络的能量层 |
|---|---|---|
| 多晶铝（训练材料） | 网络训练所用的铝 | 用训练结果 |
| 各向同性 Murnaghan（自定义常数） | 其他各向同性金属 | 换成这组 λ、μ、l、m、n |
| 自定义应变能密度 W(E) | 任意各向异性，如 CFRP | 换成由 W 求出的二阶、三阶常数 |

## 场景中的写法

```json
"material": {
  "model": "energy",
  "name": "CFRP 单向",
  "rho_kg_m3": 1560,
  "fiber_angle_deg": 0,
  "energy": "0.5*C11*E11**2 + C12*E11*(E22 + E33) + ... + a6*i4**3",
  "parameters": {"C11": 138.0, "C12": 5.02, "a6": 0}
}
```

不带 `model` 的旧写法仍然表示训练所用的铝。`"model": "murnaghan"` 使用 `rho_kg_m3, lambda_pa, mu_pa, l_pa, m_pa, n_pa`。

## W(E) 表达式

- **含义与单位：** W 是单位参考体积的应变能，单位 GPa（1 GPa = 10⁹ J/m³）。
- **坐标系：** W 写在材料坐标系中，轴 1 为纤维方向。`fiber_angle_deg` 让材料坐标系绕全局 z 轴转动，即纤维在 x–y 平面内，角度从 x 轴量起。
- **应变：** Green–Lagrange 应变 E = (FᵀF − I)/2 的张量分量 `E11 E22 E33 E12 E13 E23`。注意它们不是工程剪应变。
- **不变量：**

  | 记号 | 定义 |
  |---|---|
  | `i1` | tr E |
  | `i2` | ½[(tr E)² − tr E²] |
  | `i3` | det E |
  | `tr2` | tr E² |
  | `tr3` | tr E³ |
  | `i4` | a·E·a，纤维不变量，a 为纤维方向 |
  | `i5` | a·E²·a，纤维不变量 |

- **可用运算：** `+ − * / **`（也可写 `^`）、括号、`exp log sqrt sin cos tanh sinh cosh`，以及自定义参数。
- **安全限制：** 表达式按语法树检查，只允许上面这些写法，不能调用其他函数或访问属性。

**例：** 用不变量写的 Murnaghan 铝：

```
0.5*(lam+2*mu)*i1**2 - 2*mu*i2 + (l+2*m)/3*i1**3 - 2*m*i1*i2 + n*i3
```

取 lam = 58.1、mu = 26.1、l = −143、m = −297、n = −345（GPa），结果与原 Murnaghan 本构一致到 1e-12，与网络训练得到的能量层一致到 1e-15。

## 预设

**CFRP 单向板（横观各向同性）**

二阶部分用 Voigt 常数 C11、C12、C22、C23、C55 书写（纤维为轴 1）：

```
0.5*C11*E11**2 + C12*E11*(E22 + E33) + 0.5*C22*(E22**2 + E33**2) + C23*E22*E33 + (C22 - C23)*E23**2 + 2*C55*(E12**2 + E13**2)
```

即 C13 = C12，C33 = C22，C44 = (C22 − C23)/2，C66 = C55。

三阶部分用横观各向同性的 9 个三次不变量，系数为 a1–a9：

```
a1*i1**3 + a2*i1*tr2 + a3*tr3 + a4*i1**2*i4 + a5*i1*i4**2 + a6*i4**3 + a7*i1*i5 + a8*tr2*i4 + a9*i4*i5
```

- **二阶常数：** 默认值由 E1 = 135、E2 = 9、G12 = 5 GPa、ν12 = 0.3、ν23 = 0.45 算出，只代表单向碳/环氧材料的量级，不是某个牌号的认证数据。界面中可由实测工程常数一键换算。
- **三阶系数：** a1–a9 默认全为 0。此时材料非线性只来自几何非线性，相当于各向异性的 StVK。要计算材料非线性，需要填入由实验（声弹性、二次谐波测量）或文献得到的三阶系数。

**正交各向异性：** 9 个二阶常数 C11 … C66，可以在表达式后面追加任意三阶项。

## 软件如何使用 W

1. **求导：** 对 W 求导，得到零应变处的二阶常数 c2（6×6）和三阶常数 c3（6×6×6），均为 Mandel 坐标。
   - 一阶导数用复步长法，精确到舍入误差；
   - 二阶、三阶导数用步长 1e-4 的中心差分；
   - 求得的张量再做对称化，并按纤维角旋转到全局坐标。
2. **检查：**
   - 零应变处必须无应力，即 W 不能含应变的一次项；
   - 二阶刚度必须正定；
   - 报告 W 中四阶及以上项在应变 1e-3 时相对三阶项的大小（截断余项）。
3. **计算：** 所有求解都用 W ≈ ½ c2:E:E + ⅙ c3:E:E:E。三组响应的含义：
   - 线性：小应变，只用 c2；
   - StVK：Green 应变，只用 c2；
   - 完整：Green 应变，c2 + c3；
   - 材料非线性增量（完整 − StVK）就是三阶常数的贡献。
4. **网格和时间步：**
   - 时间步取全方向最快的准纵波速，至少按 10000 m/s 计算，保持在网络验证过的 Courant 数范围内；
   - 网格检查和 2f 分辨率取全方向最慢的准剪切波速。
5. **核对用数据：** 材料面板给出三组标准应变下的第二 Piola 应力（MPa），可以用来核对在 COMSOL 等软件中实现的同一个 W。对铝，这三组值与 COMSOL 本构自检表相同。

## 物理 AI 为什么能直接用于新材料

冻结网络的能量层，本身就是 Mandel 坐标中的三次应变能多项式：

- `quadratic_tensor` = c2 / 2e11，`cubic_tensor` = c3 / 6e11（见 `graphwave/inference.py` 的 `energy_activation`）；
- 铝只是这组张量的一个取值；
- 网络学到的求导滤波器和时间组合与材料无关（它们等于 GLL 谱元算子和四阶时间组合）。

所以换材料时：

- 求导滤波器和时间层沿用训练结果；
- 能量层换成由 W 求出的常数；
- 不改动任何冻结文件，也不需要重新训练。

**验证：** 对 CFRP 预设（三阶系数非零，纤维转 30°，含双激励、对称面和吸收层），把网络的状态权重设为 1，网络与独立编写的各向异性谱元核 `spectral3d/anisotropic.py` 在 StVK 和完整非线性两种响应上的差异都小于 1e-10，能量收支闭合（`graphnet/test_graphnet.py`）。

**精度的含义：** 这说明网络对新材料的计算与谱元格式一致，但精度仍由网格分辨率决定。新材料、新几何的结果要用细网格谱元参考或 COMSOL 逐例核对。

## 目前的限制

- **铺层：** 材料在整个结构中均匀，纤维角只有一个。叠层板（逐层不同纤维角）尚未支持。
- **求解器：** 自定义应变能材料只能用三维显式谱元（`spectral3d`）和物理 AI 网络；隐式 Newmark、二维平面应变、四面体有限元仍只支持各向同性 Murnaghan。
- **高阶项：** 求解使用三阶展开。对超声应变（不超过 1e-3）这通常足够，面板中的截断余项会提示例外。
