# 有限宽铝板的直达波与材料二次谐波

三维超弹性页面的五组对照完成后，可点击“使用建议直达波窗”，或“比较预设点的直达波（X 方向）”。后者从已有完整场依次读取 3–8 个接收点，不启动新求解。接收点应沿同一 X 方向路径，保持相同 Y/Z 坐标。比较图保持这些点的 X 位移和等长移动窗；单点查看器仍可改变方向与时间窗，改变后不会继承原选择的数值验证结论。

建议窗只用于无孔直板、自由边界、完整 X 端面沿 X 方向牵引。管、孔洞、缺口、CAD、局部贴片或横向激励没有自动建议窗，仍可手动查看已有波形。本功能不推断这些结构的模态。

## 窗口和物理检查

用各向同性自由无限宽板的 Rayleigh–Lamb 方程求 S₀ 候选分支，分别计算 f 和 2f 的相位速度与群速度。支持的频厚积为 f·板厚 ≤ 1.2 MHz·mm，两频率均须满足。这里的有限宽三维板不一定传播同一个模态；求得候选根不等于完成模态分解。

距加载端 d 处，建议窗为：

```text
arrival = source_delay + d / vg(f)
window = [arrival − 0.5/f, arrival + (cycles + 0.5)/f]
distal_echo_estimate = source_delay + (2L − d) / (1.05 cL)
```

所有点的窗长相同，需完整位于记录中，结束时间应早于预计远端回波。1.05 cL 是保守的工程速度估算，不是非线性波前的严格数学上界。这项检查仅针对远端；不会排除侧向模态、近场或其他波包，也不保证有限脉冲的全部能量都在候选窗口内。

同时给出 Δk = k(2f) − 2k(f)、相干长度 π/|Δk| 和两频率的群速度走离。候选相位匹配因子 sinc(Δk·d/2) 只描述相位差，未包含模态非线性耦合积分，不能由它单独预测实际二次谐波幅值。

实际波形的线性基频复数相位沿相邻点比较，以预测 k(f) 辅助选择相位分支，再给出推断波数的相对差异。5% 是本研究采用的比较阈值；通过仍不证明模态纯度，未通过则明确提示不能按纯 S₀ 解释。分析保留材料/几何控制、浮点存储误差、平方标度和离散精度检查，详见 [solid-harmonics.md](solid-harmonics.md)。

## 可复现运行

普通启动不得自动运行研究。明确开始一个新数值对照时，可提供经过校验的场景 JSON：

```sh
/workspace/workai-remote/solid/venv/bin/python tools/run-solid-harmonic-validation.py --evidence NEW-UNUSED-DIR --scene SCENE.json --mesh-sizes .6 .45
node tools/review-solid-harmonics.mjs /workspace/workai-remote NEW-UNUSED-DIR --direct-windows
/workspace/workai-remote/solid/venv/bin/python tools/verify-solid-harmonics.py /workspace/workai-remote NEW-UNUSED-DIR
node tools/link-solid-harmonic-validation.mjs /workspace/workai-remote NEW-UNUSED-DIR
node tools/export-solid-propagation.mjs /workspace/workai-remote NEW-UNUSED-DIR NEW.html
```

三层共 15 组真实三维有限元计算；同层五组复用精确网格，时间步细化复用细网格。离散验证限于指定点、方向和窗口。独立 NumPy 重算插值与复数系数属于分析交叉核对，不是独立物理求解器或实验对标。

沿程 HTML 保存所有指定接收点的五组三分量波形，可离线切换点位、接收方向、窗口、信号和频谱，并导出 CSV/JSON。它不包含其他位置的完整场；其他点位需回工作台提取。HTML 不需要网络，不含连接凭据。
