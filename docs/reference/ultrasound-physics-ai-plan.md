# 超声无损检测物理AI仿真软件规划

Oct 11, 2026 · @Karen Martinez

建议做成“数值真值引擎 + 物理AI加速层”的混合求解软件：每个结果都带误差指标，超出阈值自动回退数值求解，以此保证与 COMSOL 精度相当。内容覆盖换能器、激光超声、波型与波导、材料、物理现象、缺陷与检测方法六个域。交互用“指令窗—执行窗—结果窗”三窗口，取代模型树式的逐项点选。表中优先级：P0 为第一优先级，P1 为第二阶段，P2 为远期；一个人开发时，首版只取 P0 中的三个场景，见开发计划页。

首版的里程碑、技术取舍、分工与风险见 首版开发计划。

实现规格（场景文件、COMSOL 翻译器、AI 代理、路由、界面、逐周任务）见 详细技术方案。

对当前界面（构建 0.3.1）的修改建议见 界面修改方案。

## 1 技术路线：数值真值引擎 + 物理AI加速层

要与 COMSOL 精度相当，核心求解不能只靠神经网络。建议数值引擎与物理AI并存，由误差校验器在两者之间路由。

- **纯 PINN 不适合做主求解器。** 物理信息神经网络偏向先学低频成分，对高频、多尺度波场收敛困难（[Wang 等，2021](https://doi.org/10.1016/j.cma.2021.113938)）。超声检测的计算域常跨几十到上百个波长，正处于其弱项。
- **神经算子适合做代理模型，但依赖数值真值。** 三维弹性波算子 [MIFNO](https://arxiv.org/abs/2404.10115) 用 3 万组数值仿真训练，80% 的预测达到“优秀”相位吻合度。仍有约两成未到该等级，所以每次结果都要校验，不达标就回退。
- **超声领域已有先例。** 激光激发表面波的神经算子正演与反演已用于无损评价研究（[Liu 和 Su](https://ira.lib.polyu.edu.hk/handle/10397/117448)）。
- **数值引擎本身要够快。** GPU 显式有限元软件 [Pogo](https://www.imperial.ac.uk/non-destructive-evaluation/publications-products-and-services/pogo/) 比 CPU 同类最多快约 100 倍，已算过超过 30 亿自由度的三维模型。自研数值引擎建议走同一路线。
- **差异化不在拼求解速度。** COMSOL 自 5.5 版起提供时域显式间断伽辽金弹性波接口（[发布报道](https://audioxpress.com/news/version-5-5-of-comsol-multiphysics-is-now-available)）。[6.4 版](https://www.comsol.com/press-release/comsol-speeds-simulation-with-expanded-nvidia-gpu-support-for-comsol-multiphysics-version-64-14612)于 2025 年 11 月 18 日发布，[多 GPU 加速](https://www.comsol.com/release/6.4/acoustics-module)覆盖时域显式压力声学，发布说明中还设有代理模型专栏。[CIVA 2025](https://www.extende.com/newsletters/newsletter-december-2025/) 在 UT 模块加入了完整有限元。本软件的差异应放在秒级 AI 响应、指令式交互和检测工艺闭环。

### 求解器清单

| 求解器 | 类型 | 承担的任务 | 优先级 |
| --- | --- | --- | --- |
| 时域谱元 / 显式有限元（GPU） | 数值真值 | 任意几何、各向异性、流固耦合的全波场；生成训练数据；回退求解 | P0 |
| 半解析有限元（SAFE） | 数值 | 任意截面波导的频散曲线、模态振型、激励性 | P0 |
| 全局矩阵 / 刚度矩阵法 | 解析 | 多层板与管的频散、反射与透射系数 | P0 |
| 神经算子代理（FNO、DeepONet、图网络） | 物理AI | 参数化工况的秒级全波场与 A 扫预测 | P0（限定场景） |
| 误差估计与路由器 | 校验 | PDE 残差、能量守恒、互易性、抽样数值复核；决定采用 AI 结果还是回退 | P0 |
| 频域有限元 / 边界元 | 数值 | 缺陷散射矩阵、压电阻抗谱、稳态声场 | P1 |
| 声线、多高斯声束、分布点源法 | 半解析 | 换能器声场与相控阵延时法则的快速计算 | P1 |
| 时域有限差分 / k 空间伪谱 | 数值 | 规则网格下的流体与弱非均匀介质、非线性声传播 | P1 |
| 局部散射子域 + 全局传播拼接 | 混合 | 缺陷附近用有限元或 AI，传播区用解析或声线，避免全域重算 | P1 |
| 物理约束训练与可微求解器 | 物理AI | 小数据微调、材料与缺陷参数反演 | P1 |

子域拼接已在显式有限元中有成熟做法：主域只算一次无缺陷入射场，缺陷只在小子域内重算（[Wilcox，BINDT 2024](https://www.bindt.org/events-and-awards/ndt-2024/abstract-1a3/)）。

## 2 软件总体架构

软件分六层，层与层之间只传递一份“场景文件”：指令被解析成场景文件，求解器读取它，结果反过来引用它。自然语言、命令和 Python 三种入口因此得到同一个可复现的任务。

&#91;embedded content: 总体架构 · 6 层，24 个模块\]

指令自上而下经过编排、建模、求解、后处理，结果回到结果窗；数据与模型层为各层提供存储、训练样本和基准算例。

### 模块与技术选型

| 模块 | 职责 | 建议实现 |
| --- | --- | --- |
| 界面 | 三窗口、二维与三维视图 | Qt（PySide6）或 Web 前端；三维渲染用 VTK / PyVista |
| 指令解析 | 自然语言与命令 → 场景文件 | 大模型输出受 JSON Schema 约束；命令语言用 Python 语法子集 |
| 场景文件 | 几何、材料、探头、缺陷、求解设置的唯一描述 | YAML / JSON，带版本号与校验规则 |
| 几何与网格 | 参数化几何、CAD 导入、六面体与四面体网格 | OpenCASCADE、Gmsh |
| 数值引擎 | 谱元 / 显式有限元、SAFE、频域求解 | C++ / CUDA 内核，Python 绑定 |
| AI 引擎 | 训练、推理、模型仓库 | PyTorch；算子模型可借用 [NVIDIA PhysicsNeMo](https://github.com/NVIDIA/physicsnemo)（原 Modulus）；推理导出 ONNX |
| 校验与路由 | 误差估计、求解器选择、回退 | 独立服务，阈值可按任务配置 |
| 后处理 | 滤波、时频分析、频散提取、TFM 等成像 | NumPy / SciPy，GPU 上用 CuPy |
| 数据 | 波场、A 扫、元数据 | HDF5 / Zarr；每个结果记录场景文件哈希、求解器版本、误差指标 |
| 扩展 | 用户自定义材料、探头、求解器、成像算法 | 插件接口 + Python API |

| 相控阵 | 一维线阵、二维面阵、环形阵、凸阵与凹阵、柔性阵；偏转、聚焦、扇扫延时法则；栅瓣与阵元串扰 | 声束指向性、焦点尺寸、全矩阵数据 | P0 |
| 导波换能器 | 压电晶片、梳状换能器、角楔式、管道用磁致伸缩带与压电环 | 模态选择性、激励性曲线 | P0 |
| 激励与电路 | 尖脉冲、方波、汉宁窗正弦串、线性调频、编码激励；电缆、匹配电路、放大器、模数转换量化与噪声 | 系统级 A 扫 | P0 |

| 光源参数 | 脉宽（纳秒、皮秒、飞秒）、能量、波长、重复频率；点、线、环、阵列、光栅条纹光斑；时空调制 | 激发频谱与带宽 | P0 |

| 激发波型 | 表面波、头波、掠面纵波、体纵波与横波、兰姆波 | 波形与到达时间 | P0 |
| 光学检测 | 共焦法布里-珀罗、迈克尔逊与外差干涉、双波混合、激光多普勒测振、光束偏转法；粗糙表面散斑 | 面外或面内位移信号、检测带宽与噪声 | P1 |

| 应用模板 | 增材制造在线监测、复合材料检测、薄膜与涂层表征（表面波频散）、高温与运动件检测、晶粒尺寸评估、激光-EMAT 混合 | 工艺参数建议 | P1 |

## 6 仿真内容：材料模型

## 8 仿真内容：缺陷、工件与检测方法

## 10 与 COMSOL 的对标验证

“精度相当”要先量化：建议以同一算例下相对 COMSOL 收敛解的波形误差和到达时间误差作为验收指标。下表阈值是建议值，待确认。

### 验收指标

| 指标 | 定义 | 建议阈值 |
| --- | --- | --- |
| 波形误差 | 接收点 A 扫的相对 L2 误差（见下式） | ≤ 5% |
| 到达时间误差 | 主波包互相关时延 | ≤ 中心周期的 1/20 |
| 幅值误差 | 主回波峰值偏差 | ≤ 0.5 dB |
| 频散曲线误差 | 相速度相对偏差 | ≤ 0.5% |
| 反射与透射系数 | 与参考值的绝对偏差 | ≤ 0.02 |
| 谐振频率 | 谐振与反谐振频率的相对偏差 | ≤ 0.5% |

```latex
e_{L2} = \frac{\lVert u - u_{\mathrm{ref}} \rVert_2}{\lVert u_{\mathrm{ref}} \rVert_2}
```

### 验证方法

- **参考解必须是收敛解。** COMSOL 侧先做网格和时间步加密研究，否则比较的是两边各自的离散误差。
- **三级基准逐级推进。** 先对解析解，再与 COMSOL 交叉验证，最后对实验数据。
- **AI 模型单独验收。** 按训练分布内、分布边缘、分布外三组测试，报告误差的 95 分位数而不是平均值。
- **自动回归。** 基准算例入库，求解器或模型每次更新后自动重跑，结果窗直接生成对比报告。
