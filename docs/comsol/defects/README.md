# 缺陷模型的 COMSOL 对照运行：仿真要求与输出要求

软件 1.1 加入了裂纹、分层、接触界面、缺口和孔，见[缺陷说明](../../defects.md)。这些缺陷的网络计算已经做过下面这些检查：

- 网格与网络和同一网格上的 GLL 谱元求解器一致到 1e-10；
- 体积和均匀应变能精确；
- 接触界面的受压透射、受拉张开与一维解析行为一致。

但这些检查都用的是同一种离散。要确认裂纹、分层的散射和闭合缺陷的接触非线性在物理上是对的，需要一个**独立求解器**。下面 7 次 COMSOL 运行就是为此准备的。每次运行在 `cases/` 下都有一个完全对应的软件场景（`make_cases.py` 生成），拿到数据后可以直接逐点比较。

## 1. 优先级

| 编号 | 内容 | 本构 | 幅值 A | 检查什么 | 优先级 |
|---|---|---|---|---|---|
| D0 | 无缺陷参考 | 线性 | 1 MPa | 激励、吸收层、接收点是否与软件一致（散射量都相对它计算） | 必做 |
| D1 | 开口表面裂纹 x = 30，深 0.8 mm | 线性 | 1 MPa | 裂纹的反射、透射和 A0/S0 模式转换 | 必做 |
| D4 | 闭合表面裂纹（接触，无摩擦，初始间隙 0） | 线性 | 1 MPa | 接触非线性（拍击）产生的 2f、3f | 必做 |
| D5 | 同 D4 | 线性 | 2 MPa | 零间隙、无预压时接触是一次齐次的：响应和谐波都应正好放大 2 倍，用来检查接触实现 | 必做 |
| D2 | 开口分层 x = 25–35，距上表面 0.8 mm | 线性 | 1 MPa | 分层的散射 | 建议 |
| D3 | 横孔（侧钻孔，贯穿板宽）x = 30，z = 0.8，半径 0.4 mm | 线性 | 1 MPa | O 型曲边网格的散射 | 建议 |
| D6 | 闭合分层（接触） | 线性 | 1 MPa | 层间接触非线性 | 可选 |

本构全部用小应变线性弹性，这样缺陷和接触的效应不会和材料非线性混在一起。材料非线性 P1 已经单独核对过。

## 2. 模型设置（所有运行相同）

### 2.1 几何与坐标

- 铝板长 60 mm（x），宽 2 mm（y），厚 1.6 mm（z），坐标原点在一角，z = 1.6 为上表面。
- y = 2 mm 为**对称面**（法向位移 u_y = 0），所以这是 4 mm 宽板的半模型。其余面自由。
- 缺陷都贯穿整个半宽（0 ≤ y ≤ 2），在完整模型中贯穿 4 mm 全宽。横孔的轴沿 y，从 y = 0 贯穿到对称面。

| 缺陷 | COMSOL 中的做法 |
|---|---|
| 开口裂纹（D1） | 零厚度内部边界 x = 30，z 从 0.8 到 1.6。两侧不连接、两面自由（COMSOL 6.x 固体力学的 **Crack** 节点，或用 Form Assembly 生成一对、两侧都不施加连续性）。不要用有厚度的槽代替。 |
| 开口分层（D2） | 零厚度内部边界 z = 0.8，x 从 25 到 35，两面自由。 |
| 横孔（D3） | 圆柱孔，轴沿 y，圆心 (x, z) = (30, 0.8)，半径 0.4 mm，孔面自由。 |
| 闭合裂纹 / 分层（D4–D6） | 与 D1、D2 同一几何，两面定义**接触对**：法向接触，**无摩擦**，**初始间隙 0**，**无预压**。用罚函数或增广拉格朗日均可，请在元数据中写明方法和罚刚度。受压时传力，受拉时张开。 |

### 2.2 材料

多晶铝：ρ = 2700 kg/m³，λ = 58.1 GPa，μ = 26.1 GPa。线性弹性，没有材料阻尼。与 P1 相同。

### 2.3 激励

固定方向的名义牵引，按参考面积计（死载荷），作用在上表面 z = 1.6 整面：

```text
T(x, y, t) = A · exp(−[(x − 15)² + (y − 2)²] / (2·2²)) · s(t) · (0, 0, −1)      （长度单位 mm）
s(t) = ½[1 − cos(2π f t / 5)] · sin(2π f t)，0 ≤ t ≤ 5/f；其余时刻为 0
f = 0.3 MHz，5 个周期，延迟 0
```

高斯中心在对称面上，所以完整模型中是一个完整的高斯斑。

### 2.4 吸收层

两端各 10 mm，质量比例阻尼体载荷，三个分量都加：

```text
f = −ρ · α(x) · ∂u/∂t
左层（x 从 0 到 10 mm）：  α(x) = α_max · ((10 − x) / 10)³
右层（x 从 50 到 60 mm）：α(x) = α_max · ((x − 50) / 10)³
α_max = 1.7660492 × 10⁷ 1/s
```

不要用 PML 或低反射边界代替。用 Rayleigh 质量阻尼时，α_dM 取同一个 α(x)。

### 2.5 时间与输出

- 初始位移、速度为 0。
- 计算 0–35 μs，在 0、0.05 …… 35 μs 精确输出，共 701 个时刻。
- 输出 10 个接收点的位移 u_x、u_y、u_z，单位 m，取参考构形中的固定点：

| 名称 | (x, y, z) mm |
|---|---|
| top_20、top_25 | (20, 2, 1.6)、(25, 2, 1.6)：缺陷前（入射 + 反射） |
| top_35、top_40、top_45 | (35, 2, 1.6)、(40, 2, 1.6)、(45, 2, 1.6)：缺陷后（透射） |
| mid_20 … mid_45 | 同样的 x，z = 0.8（板厚中面，区分对称 S0 与反对称 A0） |

### 2.6 网格与求解器

| 项目 | 要求 |
|---|---|
| 单元 | 六面体扫掠网格，二次单元 h ≤ 0.2 mm（缺陷 1 mm 范围内 h ≤ 0.1 mm）；或四阶单元 h ≤ 0.4 mm |
| 厚度方向 | 二次单元至少 8 层，裂纹尖端、分层边缘处有网格线 |
| 时间积分 | 广义 α 法，ρ∞ = 1（无数值耗散），最大步长 ≤ 0.005 μs，输出时刻严格命中 |
| 容差 | 时间相关求解器相对容差 ≤ 1e-6；接触迭代收敛到接触压力相对变化 ≤ 1e-6 |
| 收敛变体 | D1 与 D4 各再算一次 mesh2（h 乘 0.7）。接触问题的数值敏感度高，这一次很重要 |

## 3. 交付格式

- 文件名：`<编号>.csv`，例如 `D1-open-crack.csv`；收敛变体 `D1-open-crack_mesh2.csv`。编号与 `cases/` 下的文件名一致。
- CSV：可以先有若干行以 `%` 或 `#` 开头的注释，然后一行表头，表头与 [header-template.csv](header-template.csv) 完全相同（31 列：`time_us` 和 10 个接收点 × 3 个分量），然后 701 行数据。位移单位 m，**至少 12 位有效数字**，科学计数法。
- 每次运行一个 `<编号>.json` 元数据，按 [metadata-template.json](../metadata-template.json) 填写。接触运行请写明：接触方法、罚刚度或增广拉格朗日参数、接触面上的最大穿透量、最大接触压力。
- 全部放在一个文件夹里打包。`.mph` 文件可选。

## 4. 拿到数据后我会做的比较

1. COMSOL 自身：mesh2 与基准的差异。
2. 用同一场景（`cases/*.json`）在软件里计算，逐点比较：
   - 散射场：缺陷运行减去 D0 的波形，以及其在 f 处的幅值和相位；
   - 闭合缺陷：2f、3f 的幅值，D5 与 D4 之比是否为 2；
   - 门槛沿用 P1：波形差和 f、2f 幅值差 5% 以内。
3. 罚刚度的影响：软件的接触罚刚度由时间层稳定性决定，受压时的反射在 0.3 MHz 约 1%（计算诊断里给出）。如果和 COMSOL 的差别主要来自这里，会单独列出。
