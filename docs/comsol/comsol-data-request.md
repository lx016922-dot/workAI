# COMSOL 仿真要求与数据要求

这批 COMSOL 结果有两个用途：

1. **独立核对训练标签。** 粗网格算子的标签由仓库内的谱元求解器计算。用另一个求解器算出同样的结果，核对就不依赖我们自己的代码。
2. **补充训练和测试数据。** 粗网格模型在训练中没见过的双贴片激励上，非线性增量的 2f 不达标。这类工况是最需要的数据。

每个工况的完整定义都在 `docs/comsol/cases/<工况编号>.json`，与我们的谱元标签逐项一致。下文是同一内容的说明。拿到数据后，用 `python -m coarsegraph.comsol` 检查、导入和比较。

## 1. 优先级与工作量

| 优先级 | 工况 | 每个工况要算的运行 | 运行数 |
|---|---|---|---|
| P1，必做 | A-f0.40-T1.6、B-f0.40-T1.6、C-f0.25-T2.0 | linear、stvk、murnaghan 基准各一次；linear 与 murnaghan 再各做网格加密（mesh2）和时间步减半（dt2） | 3 × 7 = 21 |
| P2，建议 | A-f0.30-T2.4、A-f0.40-T2.0、B-f0.30-T2.4、C-f0.35-T2.0 | linear、murnaghan，stvk 可选 | 8–12 |
| P3，可选 | 其余 10 个 | linear、murnaghan | 20 |
| 可选 | P1 工况 | 载荷加倍（amp2）的 stvk、murnaghan，用于 A/2A 标度检查 | 6 |

先交 P1。P1 的数据就足以判断两个求解器是否一致，以及 COMSOL 侧是否收敛。

## 2. 模型设置（所有工况相同）

### 2.1 几何与坐标

- 半宽铝板：x 从 0 到 48 mm，y 从 0 到 2 mm，z 从 0 到 T mm，T 见工况表（1.6、2.0 或 2.4 mm）。
- y = 2 mm 的面是对称面：u_y = 0，其余两个分量自由。
- 其他面都是自由面，加载面除外。不要建全宽模型，也不要把对称面放在 y = 0。
- 全部使用 SI 单位，坐标在文件中以 mm 给出。

### 2.2 材料与三组本构对照

| 参数 | 值 |
|---|---|
| ρ₀ | 2700 kg/m³ |
| λ | 58.1 GPa |
| μ | 26.1 GPa |
| l | −143 GPa |
| m | −297 GPa |
| n | −345 GPa |

本构用 Green–Lagrange 应变 E = (FᵀF − I)/2 写成：

```text
i₁ = tr E,  i₂ = ((tr E)² − tr(E²)) / 2,  i₃ = det E
W = ½(λ + 2μ) i₁² − 2μ i₂ + ⅓(l + 2m) i₁³ − 2m i₁ i₂ + n i₃
S = ∂W/∂E,  P = F·S（全 Lagrange 格式，第一 Piola 应力）
```

| 对照 | 文件名中的名称 | 设置 |
|---|---|---|
| 线性 | `linear` | 几何线性、小应变 Hooke 定律 |
| StVK | `stvk` | 几何非线性，W 只取 λ、μ 两项 |
| Murnaghan | `murnaghan` | 几何非线性，W 取全部五项 |

**本构自检，必做。** COMSOL 自带 Murnaghan 模型中 l、m、n 的约定可能与上式不同，这是最容易出错的地方。请用单个单元施加均匀变形，使 Green 应变等于下表的值，读出第二 Piola 应力 S，与下表比较，要求 4 位有效数字一致，并把结果写进元数据：

| 应变态 E | 期望的 S（MPa） |
|---|---|
| E11 = 1e-3，其余为 0 | S11 = 109.563，S22 = S33 = 57.957，切向为 0 |
| E12 = E21 = 1e-3，其余为 0 | S12 = 52.2，S11 = S22 = −0.594，S33 = −0.249 |
| E = [[1, 0.4, −0.2], [0.4, −0.5, 0.3], [−0.2, 0.3, 0.7]] × 1e-3 | S = [[120.89172, 20.71218, −10.30434], [20.71218, 43.28142, 15.57726], [−10.30434, 15.57726, 105.52146]] |

剪切那一行能区分 m 和 n 的约定。如果自带模型对不上，请像之前那样用弱式直接写 W。

### 2.3 激励

每个源都是固定方向的名义牵引，按参考面积计，属于死载荷，不是随动载荷或压力：

```text
T₀(X, t) = A · w(X) · s(t − t₀) · d
s(τ) = ½[1 − cos(2π f τ / N)] · sin(2π f τ)，0 ≤ τ ≤ N/f；其余时刻为 0
A = 1 MPa，N = 5 个周期，相位为 0
```

| 族 | 加载面 | 空间分布 w(X) | 方向 d | 延迟 t₀ |
|---|---|---|---|---|
| A 顶面高斯 | 顶面 z = T 整面 | exp(−[(x − 16)² + (y − 1)²] / (2·2²))，长度单位 mm | (0, 0, −1) | 0 |
| B 端面轴向 | 左端面 x = 0 整面 | 1，均匀 | (1, 0, 0) | 0 |
| C 双贴片反相 | 顶面 z = T 整面，两个源叠加 | 源 1：中心 (13, 1)，σ = 1.5 mm；源 2：中心 (19, 1)，σ = 1.5 mm | 源 1：(0, 0, −1)；源 2：(0, 0, +1) | 源 1：0；源 2：1 μs |

高斯分布作用在整个顶面上，不要截成小圆片。f 见工况表；C 族两个源的频率相同。

### 2.4 吸收层

吸收层用质量比例阻尼，写成体载荷，三个分量都加：

```text
f = −ρ₀ · α(x) · ∂u/∂t                         （每单位参考体积）
左层（x 从 0 到 8 mm）：  α(x) = α_max · ((8 − x) / 8)³
右层（x 从 40 到 48 mm）：α(x) = α_max · ((x − 40) / 8)³
α_max = 2.2075616 × 10⁷ 1/s
```

A、C 两族两端都有吸收层，B 族只有右层。不要用 PML 或低反射边界代替；不要加刚度比例阻尼或其他材料阻尼。如果用 Rayleigh 质量阻尼，α_dM 取同一个 α(x)，且必须确认它在几何非线性和 Murnaghan 模型下都生效。

### 2.5 初始条件、时间与输出

- 初始位移、速度都为 0。
- 计算 0 到 30 μs，在 0、0.05、0.10 …… 30 μs 精确输出，共 601 个时刻。
- 输出接收点处的位移 u_x、u_y、u_z，单位 m。在参考构形（材料坐标）中的固定点取值，不随变形移动。非线性增量只有位移的万分之一左右，取值方式不同造成的差异可以与之相当。

### 2.6 网格与求解器

| 项目 | 要求 |
|---|---|
| 单元 | 六面体扫掠网格；二次单元时各方向 h ≤ 0.4 mm，四阶单元时 h ≤ 0.8 mm |
| 厚度方向 | 二次单元至少 4 层 |
| 积分阶次 | 能精确积分三阶能量的弱式：二次单元不低于 12，四阶单元不低于 20 |
| 时间积分 | 广义 α 法，ρ∞ = 1，即无数值耗散；最大步长 ≤ 0.01 μs；输出时刻严格命中 |
| 容差 | 非线性增量约为位移的 1e-4，要解到 1%，所以时间相关求解器的相对容差 ≤ 1e-6，Newton 迭代的位移相对变化 ≤ 1e-8 |
| 检查 | 全部输出时刻的 Green 应变 Frobenius 范数 ≤ 1e-3，J > 0 |

二次单元、h = 0.4 mm 时约 7 万到 10 万自由度，3000 个时间步。

**收敛变体（P1 必做）。** mesh2：其他设置不变，h 乘以 0.7，或单元阶次加 1。dt2：最大步长减半到 0.005 μs。

## 4. 交付格式

**文件名**

```text
<工况编号>_<linear|stvk|murnaghan>.csv            基准运行
<工况编号>_<linear|stvk|murnaghan>_<mesh2|dt2|amp2>.csv   变体
<工况编号>.json                                     该工况的运行元数据
```

例如 `A-f0.40-T1.6_murnaghan.csv`、`A-f0.40-T1.6_linear_mesh2.csv`。

**CSV 内容**

- 开头可以有以 `%` 或 `#` 开头的注释行。
- 接着是一行表头，必须与 `docs/comsol/header-template.csv` 完全相同，共 40 列：`time_us`，然后每个接收点按上面的顺序各三列 `<名称>_ux_m, <名称>_uy_m, <名称>_uz_m`；名称中的方括号写成下划线，例如 `top_0_ux_m`。时间若以秒为单位，第一列写 `time_s`。
- 之后是 601 行数据，每行对应一个输出时刻。
- 位移单位为 m，至少 12 位有效数字，用科学计数法。COMSOL 导出默认只保留约 5 位，必须调高，否则非线性增量会被舍入误差淹没。

**元数据** 按 `docs/comsol/metadata-template.json` 填写，包括 COMSOL 版本、单元类型和阶次、网格尺寸、单元数、自由度、积分阶次、时间积分与容差设置、载荷与吸收层的实现方式、本构自检的 S 值，以及每次运行的耗时、步数、最大 Green 应变和最小 J。保存的 `.mph` 文件可一并提供，不是必须。

把全部文件放在一个文件夹里打包即可。

## 5. 交付前自检

```sh
python -m coarsegraph.comsol check <数据文件夹>
```

它逐个检查文件名、表头、行数、时间网格、有效数字和元数据，并给出以下提示：
- 峰值与参考相差 2 倍以上，或符号相反、时刻偏离 2 μs 以上，提示检查单位、方向和时间零点。
- 非线性运行与线性运行几乎完全相同，或差别远超预期，也会提示。

正常情况下：
- 峰值在几到几十 nm 之间。
- 对 P1 三个工况，我们的谱元结果中 murnaghan 与 linear 的最大相对差为 5.9e-5 到 3.7e-4，COMSOL 结果应在同一量级。

## 6. 拿到数据后

```sh
python -m coarsegraph.comsol import  <数据文件夹> --output <导入目录>
python -m coarsegraph.comsol compare --comsol <导入目录> --labels <谱元标签目录…>
```

我会依次报告：
1. COMSOL 自身的收敛情况，即 mesh2、dt2 与基准的差异。
2. 谱元标签与 COMSOL 的差异，用与粗网格模型相同的 5% 门槛，覆盖波形、f、2f 和非线性增量的 2f。
3. 两者一致后，把 C 族等工况加入训练，重新训练 4 阶 h 3 mm 模型，并用留出工况重新验收。

## 7. 常见错误

- 用了压力或随动载荷，而不是固定方向的名义牵引。
- 用 PML 或低反射边界代替规定的阻尼体载荷。
- 广义 α 法保留了默认的数值耗散（ρ∞ < 1）。
- 容差偏松或导出位数不够，非线性增量失真。
- 位移以 mm 导出，或时间以 s 导出却写成 `time_us`。
- 在空间坐标而不是材料坐标处取接收点的值。
- 建成全宽模型，或对称面放错位置。
- 高斯分布被截成小区域，或 C 族第二个源漏了 1 μs 延迟和反向。
- StVK 对照没有打开几何非线性。
