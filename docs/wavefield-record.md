# 波场记录：保存一个面上每一点的波形

研究波场——比如连续波激励下带缺陷的板，像扫描激光测振那样看整个表面——需要面上**每一点**的振动波形。完整记录能给，但大模型存不下（200 × 200 × 2 mm 的板算 1 ms，每组控制要 100 GiB 以上）；精简记录只保存接收点。波场记录在两者之间：只存一个面（或全部节点）、选定的分量、每隔几个采样点存一次，float32。

## 怎么打开

“模型开发器 → 求解器配置 → 波场记录”：

| 设置 | 选项 |
|---|---|
| 波场记录 | 不保存（默认）、上表面（z 最大）的全部节点、下表面（z = 0）的全部节点、上、下两个表面的全部节点、全部节点 |
| 波场的分量 | 只存 Z 位移（离面，激光测振测到的量）、三个分量 |
| 每几个采样点存一次 | 1–1000。表单下方给出波场的时间间隔和它能分辨的最高频率 |

- 打开后记录方式按精简记录处理（波场存在精简记录里）。接收点照常保存全部采样点的 float64 波形。
- 提交前“消息”窗口给出节点数、时刻数和文件大小，并计入磁盘检查。
- 只用于默认引擎（冻结网络）。圆管没有上、下表面，只能选“全部节点”。

**大小** = 保存的时刻数 × 节点数 × 分量数 × 4 字节 × 响应种数。例：200 × 100 mm 的半块板上表面 56,953 个节点，1 ms 记录每 0.8 μs 存一次（1,251 个时刻），只存 Z、只算完整响应：0.27 GiB。

**时间抽稀怎么取**：输出采样间隔最大 0.2 μs，对低频模型是过采样。要看到 3f，波场的时间间隔取 1/(8 × 3f) 左右即可：f = 0.1 MHz 时约 0.4 μs，即每 2 个采样点存一次。

**抽稀不带滤波，注意混叠**：“每 n 个采样点存一次”是直接取点，没有抗混叠滤波。波场里高于新采样率一半的频率成分会折叠到低频上。

- 例：激励 200 kHz，想要 1 MHz 的采样率（激励频率的 5 倍，每 5 个采样点存一次，间隔 1 μs）。奈奎斯特频率是 500 kHz，接触缺陷产生的 3f（600 kHz）会折叠到 400 kHz，正好叠在 2f 上；4f（800 kHz）折叠到 200 kHz，叠在基频上。实验里的采集卡有模拟抗混叠滤波器，直接取点没有。
- 做法：按每 2 个采样点存一次（0.4 μs，2.5 MHz，能分辨到 1.25 MHz，即 6f），下载后再带滤波降到 1 MHz。MATLAB：`u1 = resample(double(u), 2, 5);`（沿时间维，自带抗混叠滤波）；Python：`scipy.signal.resample_poly(u, 2, 5, axis=0)`。文件是直接存 1 μs 的 2.5 倍。
- 只关心基频、并且确认高次谐波很弱时，可以直接每 5 个采样点存一次。

**算几种响应**：存的是线性响应和各个增量（增量先用 float64 算好再存成 float32，小的增量不丢位数），其余响应由它们相加得到。只算完整响应一组时存的就是完整响应。接触非线性在完整响应里（见[缺陷说明](defects.md)），研究它时选“仅完整响应”最省。

## 算完以后

- **下载**：结果页顶部的“波场 .mat”“波场 .npz”下载当前所选响应的波场。
- **取任意点的波形**：结果页“任意点位与方向”里填记录范围内的任意坐标，软件取最近的记录节点（返回的位置是那个节点的坐标）。没有保存的分量为零。
- “下载全部结果 ZIP”里也包含波场（在记录的各个分块文件中，节点表是 `record/wavefield.npz`）。

### 文件里有什么

| 数组 | 形状 | 含义 |
|---|---|---|
| `time_us` | [时刻] | 时间，μs |
| `points_mm` | [节点, 3] | 每个节点的坐标，mm |
| `u_m` | [时刻, 节点, 分量] | 位移，m，float32 |
| `components` | 字符串 | 保存的分量，例如 `z` 或 `xyz` |
| `x_mm`、`y_mm`、`grid_index` | [nx]、[ny]、[ny, nx] | 整个面是规则网格时才有：`u_m[:, grid_index]` 就是网格上的场 |
| `grid_index_top`、`grid_index_bottom` | [ny, nx] | 同时记录上、下两个表面时代替 `grid_index`：`u_m[:, grid_index_top]` 是上表面的场，`u_m[:, grid_index_bottom]` 是下表面的场 |
| `u_m_1` … `u_m_k`、`u_m_blocks` | [时刻块, 节点, 分量] | 只在 .mat 文件里、波场达到 2 GiB 时代替 `u_m`：按时间顺序分成 k 块 |

节点是谱元的 GLL 节点，在每个单元内**不等距**（两端密、中间疏）。做空间傅里叶变换之前要先插值到等距网格。面上有孔，或缺陷把表面节点分开时，没有 `grid_index`，按 `points_mm` 使用。

MATLAB（`grid_index` 在 .mat 文件里从 1 开始）：

```matlab
S = load('local-…-wavefield-full.mat');
uz = squeeze(S.u_m(:, :, 1));                 % [时刻, 节点]
U  = fft(uz .* hann(size(uz, 1)), [], 1);     % 每个节点的频谱
f  = (0:size(uz, 1) - 1) / (size(uz, 1) * (S.time_us(2) - S.time_us(1)));   % MHz
[~, k] = min(abs(f - 0.2));                   % 例如 2f = 0.2 MHz
A  = abs(U(k, :));                            % 每个节点在该频率的幅值
imagesc(S.x_mm, S.y_mm, A(S.grid_index)); axis image; colorbar
```

Python：

```python
import numpy as np
z = np.load('local-…-wavefield-full.npz')
uz = z['u_m'][:, :, 0]                                   # [时刻, 节点]
spectrum = np.abs(np.fft.rfft(uz * np.hanning(len(uz))[:, None], axis=0))
f = np.fft.rfftfreq(len(uz), z['time_us'][1] - z['time_us'][0])   # MHz
amplitude_map = spectrum[np.argmin(abs(f - 0.2))][z['grid_index']]  # [ny, nx]
```

.mat 是 MATLAB 5 格式，单个变量不能超过 2 GiB。更大的波场在 .mat 文件里按时间顺序分成几块（`u_m_1` … `u_m_k`，块数是 `u_m_blocks`），读入后接起来；.npz 没有这个限制，始终是一个 `u_m`：

```matlab
S = load('local-…-wavefield-full.mat');
u = S.u_m_1; for k = 2:double(S.u_m_blocks), u = cat(1, u, S.(sprintf('u_m_%d', k))); end   % [时刻, 节点]
top = u(:, S.grid_index_top(:));  bottom = u(:, S.grid_index_bottom(:));                    % 两个表面，各 [时刻, ny·nx]
% 上、下表面同一位置的离面位移：两者相等是整板弯曲，两者之差是分层张开（上表面减下表面）
opening = top - bottom;
```

例：200 × 200 × 2 mm 的整板，上、下两个表面共 455,058 个节点，1 ms 记录每 0.4 μs 存一次（2,501 个时刻），只存 Z、只算完整响应：4.24 GiB，.mat 里分成 3 块。

## 限制

- float32：相对精度约 6 × 10⁻⁸，谐波比基频低 100 dB 以内不受影响。
- 只有平板的上表面、下表面、两个表面和“全部节点”四种范围；不能只存一个矩形区域或一条线。
- 取点要落在记录的面上：板内部的点不算（离面 0.05 mm 以内才取）。
- 取点用最近的节点，不做插值。
- 软件里还没有“各点谐波幅值图”这样的波场分析；目前是导出后自己处理。
- 波场记录是计算指纹的一部分：改了设置的计算不能从旧的检查点续算。

实现：`offline/wavefield.py`（节点选取、大小、读取、导出）、`graphnet/rollout.py`（写入记录分块）。
